> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 P1_DOMAIN_CONTRACT 允许的全部 domain 概念（Effect Schema 载体），验收 = schema/value round-trip + 不变量测试全绿。

**Architecture:** 纯 domain 层，无 IO。每个概念一个文件：Schema 定义 + 类型推导 + 显式不变量。Effect 4 内置 Schema（无需 @effect/schema 依赖，D-031 的"Effect Schema"从主包引入——无版本偏差风险）。

**权威依据:** `P1_DOMAIN_CONTRACT.md`（含 D-031 type shape 节）、`DEPENDENCY_RULES.md`、PHASE1_CONTRACT P1-02。

**API 稳定性注意:** Effect 4 的 Schema 类型推导 API（`Schema.Schema.Type` vs `Value` 等）以 node_modules 实际类型为准调整，语义不变，记 deviation。

**Files:** Create `src/domain/resource-mapping.ts`; Test `tests/unit/resource-mapping.test.ts`

```typescript
const dec = (v: unknown) => Schema.decodeUnknownSync(ResourceMappingSchema)(v);

describe("ResourceMapping", () => {
  it("accepts root prefix and normalized dir prefixes", () => {
    expect(dec({ writable: ["."] })).toEqual({ writable: ["."] });
    expect(dec({ writable: ["src", "src/runtime"] })).toEqual({ writable: ["src", "src/runtime"] });

    expect(() => dec({ writable: [p] })).toThrow();
  });
  it("rejects empty mapping", () => {
    expect(() => dec({ writable: [] })).toThrow();
  });
  it("rejects non-canonical separators (must be normalized form)", () => {
    expect(() => dec({ writable: ["src\\runtime"] })).toThrow();
  });
});
```

- [ ] **Step 2: 实现**（每项必须已是 canonical 形式：normalize 后与自身相等，且不含 glob 字符）

```typescript
import { Schema } from "effect";
import { normalizeProjectPath } from "./project-path.js";

const GLOB_CHARS = /[*?\[\]]/;

const canonicalPrefix = Schema.String.pipe(
  Schema.filter((s) => {
    if (GLOB_CHARS.test(s)) return false;
    const n = normalizeProjectPath(s);
    return n.kind === "ok" && n.value === s;
  }),
);

export const ResourceMappingSchema = Schema.Struct({
  writable: Schema.Array(canonicalPrefix).pipe(Schema.minItems(1)),
});

export interface ResourceMapping extends Schema.Schema.Type<typeof ResourceMappingSchema> {}
```

（`Schema.minItems` 等 combinator 名以 d.ts 为准；语义：至少一个可写前缀、每项 canonical。）
