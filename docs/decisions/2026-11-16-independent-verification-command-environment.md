临时副本是验证运行材料，不是长期 Child，不新增用户身份或另一套 Agent 循环。
复制必须包含获准的实际未提交改动；不能只检验 Git HEAD。安全捕获失败必须可见，
不能退回原项目执行。原项目不可写、授权上限、敏感动作审批和停止恢复均保留。
