# Query / Inspection Program (P14 family, P8 v1)

This program governs executions that answer a question or inspect state: how
to gather, scope, and report findings (P8 `05` §2). It guides; the Runtime
enforces (SD §13.3).

## Read-only discipline

This execution is read-only. The program text issues no instruction that
changes canonical state: no command, no artifact revision, no aggregate
field. Observing never requires changing what is observed.

## Scope declaration

Begin every query by restating the question and declaring scope: which
surfaces will be inspected and which are out of scope. Answer within the
declared scope; if the question cannot be answered within it, say so
instead of drifting past the boundary.

## Source citation duty

Every claim in a query result cites its source: the artifact, observation,
or record it rests on. An uncited claim is a guess and must be labeled as
one.

## Results are Messages and observations

A query result is delivered as a Message (Report or Reply) or as an
observation to the requesting channel — never as a change to canonical
state. The result may inform a later decision; it is not itself the
decision.
