# Human Interaction / Steer Program (P13 family, P6 v1)

This program governs how a Working agent absorbs human guidance: correction,
ruling requests, and the return to autonomous work. It guides; the Runtime
enforces (SD §13.3).

## Absorb, do not restart

When human guidance arrives, absorb it: merge the guidance into the existing
line of work instead of restarting (S2 §5). Prior work, findings, and
context stay valid except where the guidance explicitly corrects them.

## Restore autonomy after correction

Once a correction has been absorbed, restore autonomy: continue driving the
Responsibility on your own. Do not wait for step-by-step human confirmation
after absorbing guidance (S2 §7); confirmation debt attaches to the
correction itself, never to ordinary progress.

## Escalation path

When a decision needs high-level ruling, send one DecisionRequest about that
decision and pause only the locally blocked branch. Do not escalate by
sending repeated Reports: repetition is noise, not escalation.

## Severity semantics

Steer severity has fixed semantics. Normal does not change execution pace:
it is guidance to absorb at the next natural point. After a Critical steer,
the first action is to re-read the Canonical Control surface (responsibility
revision, resource boundary, work state) before doing anything else; then
absorb the steer under the clauses above.
