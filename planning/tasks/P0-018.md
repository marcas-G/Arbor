# P0-018 — P0 convergence & result record

## Source

- DID §14.5 P0 completion criteria
- DID §14.3 Root acceptance entry
- `planning/README.md` conventions

## Depends On

- P0-016
- P0-017

## Objective

Verify that every §14.5 completion criterion holds against executed
evidence, and record the phase result. This task does not add domain
behavior.

## Inputs

- All P0 source and test artifacts.
- The task result records for P0-001 … P0-017.

## Outputs

- `planning/results/P0.result.md` containing:
  - files changed (per task);
  - source contract references (DID sections);
  - exact commands run and their outcome;
  - §14.5 criterion-by-criterion evidence;
  - deviations (or "None");
  - discovered work / raised Design Gaps (or "None");
  - the commit reference(s).
- Updated `planning/README.md` status row for P0.

## Must Hold

- The phase is not marked done from intent; only from executed verification.
- `pnpm check` must be fully green, and the actual environment versions
  (Node / pnpm) recorded.
- Any §14.5 criterion not met blocks completion.
- Any discovered undefined semantics is recorded as a Design Gap, not
  resolved here.
- All P0 Design Gaps (`planning/gaps/`) are `RESOLVED` before P0 is closed.
- Commit provenance is recorded; if the workspace is not a git repository,
  P0-001 must have initialized one.

## Must Not Decide

- Do not modify `docs/design/**`.
- Do not mark P1 or any later phase authorized.
- Do not implement P1 persistence to satisfy a criterion (P0 explicitly
  excludes it).
- Do not resolve a Design Gap here.

## Acceptance

- `planning/results/P0.result.md` contains exactly 15 §14.5 entries, one
  per criterion, checked by a committed `result-record` validator test
  (not by inspection), each with command + outcome.
- `pnpm check` is green with recorded output summary.
- `planning/README.md` reflects P0 completion and P1's blocked status
  (diff-checked).
- No `OPEN` Design Gap remains in `planning/gaps/README.md` (status-column
  check, not a free-text match).
- Commit reference(s) recorded (`git rev-parse HEAD`).

## Verification

```bash
pnpm check
pnpm test -- result-record     # validates 15 §14.5 entries in P0.result.md
pnpm test -- coverage          # §14.5 criterion coverage matrix green
git rev-parse HEAD             # commit provenance
grep -E '^\| DG-[0-9]+ .*\| OPEN \|' planning/gaps/README.md   # expect no output
```
