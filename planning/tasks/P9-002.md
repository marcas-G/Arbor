## Objective

Close the B-1 visibility gap before any injection hardening: wire the real
`ReconciliationSourceLive` into the composition root (retire the
`ReconciliationSourceStubLive` defect carrier), replace the in-memory
escalation array with durable Attention facts, and land the phase gate
assertions I-1..I-3 with a pre-fix red snapshot.

## Outputs

- Composition-root wiring change + durable escalation fact emission + `p9-recovery-visibility` suite.

## Must Hold

- Wiring: composition root binds `ReconciliationSourceLive` (requires `ToolInvocationStore`); the stub (pending → `[]`) is retired from production wiring (`04` §1.1).
- **Gate (I-1) — gates the whole phase**: stopped Execution + unsettled NonIdempotent invocation (`stopRequestedAt != null`) must **never settle `Interrupted`**:
  - refs enumerable → settles `OutcomeUnknown(ReconciliationRequired(refs))` via SettleExecution, RecoveryController authority;
  - enumeration fails (`ReconciliationSourceError`) → no settlement, no guess; remains Active + durable Attention fact; next pass retries;
  - never Interrupted / Completed / Failed.
- **Pre-fix red snapshot** (documents the defect, Story A input): before the wiring lands, the same fixture settles `Interrupted(StopRequested)` — the No.54 violation is recorded as evidence.
- **Clean case preserved (I-2)**: stopped Execution with all invocations settled (or none) still settles `Interrupted(StopRequested)` — the wiring must not regress the deterministic stub-equivalent case.
- **Durable escalation (I-3 + `04` §1.2)**: one durable Attention fact per escalated Execution per recovery fingerprint; dedup key `executionId + invocationRefs fingerprint`; repeated recovery passes are no-ops (at most one live fact); the fact event lands at the same reliable commit boundary (P7 `DeadlockAttentionRequested` pattern; P6 settlement→Inbox idempotency precedent).
- The recovery pass never resolves external reality — it enumerates refs; the owning tool decides (P4 `06` §6).
- Until P10, the fact event is the entire attention surface — presentation zero-promise; assertions read the journal.

## Must Not Decide

- No settle-rule changes (P2 `06` owns); no recovery authority variants; no Attention presentation/routing/UI (P10); no B-2 completion-fact case (P9-003); no ReconciliationSource port changes.
