# P3-001 — P3 package skeletons + harness wiring

## Source

- DID v1.7 §10.4.1, §11 P3; P2-018

## Depends On

- P2-018

## Objective

Create the P3 packages/adapters and wire the build/test harness.

## Outputs

- `packages/model-context` skeleton.
- `packages/provider-runtime` skeleton.
- `adapters/provider-fake` skeleton.
- Root `tsconfig.json` references; architecture matrix keys.
- Add the `agent-runtime -> model-context` dependency edge (the P2 skeleton deliberately omitted it).

## Must Hold

- DAG: `model-context -> domain, ports`; `provider-runtime -> ports`; `agent-runtime -> domain, ports, application, model-context`; `adapters/* -> domain, ports`.
- `model-context !-> tool-runtime`; `agent-runtime !-> provider-runtime` implementation.

## Must Not Decide

- No behavior, no services, no DDL.
- No weakening of the architecture matrix.

## Acceptance

- `pnpm build`/`pnpm typecheck` green.
- `pnpm architecture` recognizes the new packages.

## Verification

```bash
pnpm test p3-harness
pnpm check
```
