# P4-004 — Tool catalog + definitions (read/patch/shell schemas)

## Source

- P4 `01` §1, `08` §1–§4; DID v1.8 §7.6, G5/G6

## Depends On

- P4-002

## Objective

Implement the full ToolDefinition catalog with exact schemas.

## Outputs

- `ToolDefinition` records for `read`/`patch`/`shell` (name/version/hash/inputSchema/resultSchema/sideEffectSemantics).
- `ToolDefinitionStore` returning full definitions by `(name, version)`.

## Must Hold

- Exact input/result schemas are frozen contract (G6).
- `read`=ReadOnly, `patch`=Idempotent, `shell`=Reconcilable.
- Identity `(name, version, hash)` shared with the P3 `ToolDefinitionRef`.

## Must Not Decide

- No git/environment tools (P11).
- No concrete allow/deny lists (empirical).

## Acceptance

- Catalog returns the three definitions with schemas; unknown tool → None.

## Verification

```bash
pnpm test p4-catalog
pnpm check
```
