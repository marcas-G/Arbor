# P10-011 — Message-mediated Query surface + Steer/Stop/Governance action surfaces

## Source

- P10 `05` §2 (user-action surfaces, BLK-2 fix), §3 (P10/P12 boundary), §4; SD §12.5 (four verbs), §13.10 (UI 只发 Command); P8 `05` (P14 read-only program — consume-only, v1.11 G6); P6 `04` (Steer), P6 `09` (SendMessage/Inbox channel); P2 `01` (Stop)

## Depends On

- P10-002, P10-006, P10-010

## Objective

The four user-action surfaces over existing, unchanged commands: the
message-mediated Query surface, the Steer surface, the Stop
request/control surface, and the Governance Change entry presentation.

## Outputs

- Query surface (message-mediated round trip + result rendering); Steer / Stop-request / Governance surfaces; CommandGateway-only submission wiring; `p10-surfaces` suite.

## Must Hold

- **Query = message-mediated (BLK-2 fix)**: the surface submits a Query **Message** to the target workspace (P6 channel) via `SendMessage`; the workspace's cognition side spawns the **P14 Execution-bound read-only query execution** (`AdmitExecution(ExecutionBound)` + result `SendMessage` back-flow, rendered from api-contracts DTOs). **External AdmitExecution is resolver-gated exactly like Stop — P10 never calls it directly.**
- **P14 consume-only**: the P8 `05` read-only program is consumed as-is — no redefinition.
- Steer surface → `SteerWork` (severity Normal/Critical, human principal); Governance Change = entry presentation over the existing governance commands (formation approval, accept outcome, withdraw / mark-unfulfillable, etc.).
- Stop surface: P10 exposes the **request only**; requests carry a human principal identifier and are submitted exactly like any external command — P2 validates trusted Stop authority as frozen; **no resolver is implemented here (GQ4)**.
- **All surfaces submit via `CommandGateway`; none write storage directly** (SD §13.10).
- **P12 边界负断言**: no HTTP/WebSocket/CLI anywhere in the P10 tree; `apps/web` stays unbuilt; `api-contracts` is the transport-neutral surface P12 binds to (GQ6).

## Must Not Decide

- No transport protocol/auth choices; no P2 runtime-semantics change; no resolver implementation; no P14 program redefinition; no new commands.

## Acceptance

- Query round trip green end-to-end (request Message → workspace-side P14 execution → result Message/Inbox back-flow rendered); steer/stop-request/governance submissions observed as commands via the gateway with zero direct storage writes; boundary negative assertions green.
