# P7-004 — ProduceDeliverable handler + directive

## Source

- P7 `01` §3, §9; DID v1.10 §12.10 (Deliverable row), G2

## Depends On

- P7-002

## Objective

Create the Deliverable fact: the `ProduceDeliverable` handler (revision-bound result record) plus its directive realization with deterministic `sourceWorkId`.

## Outputs

- Command handler + directive handler projecting `ProduceDeliverableAuthority`.

## Must Hold

- Completed source Work is **not** rejected — a Deliverable is a result fact, not a verified result; Cancelled → `TerminalLifecycleMutation`(Work) (G2 orthogonality).
- `observedSourceWorkRevision` mismatch → `RevisionConflict`; event carries the bound `sourceWorkRevision` (No.49).
- A Work may produce multiple Deliverables; re-submitting the same `deliverableId` is absorbed by the existing CommandReceipt; no update path.
- `DeliverableProduced` is the coordinator's primary trigger (`04` §1).

## Must Not Decide

- No Deliver semantics (P7-007); no satisfaction semantics (P7-005); no quality gate (P8).

## Acceptance

- Rejection rows covered; late recording against a Completed Work revision succeeds and stays traceable.
