# P4-008 — Validate-only resource admission

## Source

- P4 `05` §3; DID v1.8 G4; SD v1.3 §4.4

## Depends On

- P4-005

## Objective

Implement validate-only ownership admission.

## Outputs

- `ResourceAdmissionService.admit(workspaceId, regions)`.

## Must Hold

- `region ⊆ ResourceBoundary`; write tools additionally require an active ownership claim.
- Uses the frozen contains/overlaps algebra.
- Never mutates `resource_ownership`.

## Must Not Decide

- No claim/release.
- No boundary mutation.

## Acceptance

- Out-of-boundary region → Denied; in-boundary read-only → Admitted; no DB mutation.

pnpm test p4-resource-admission
