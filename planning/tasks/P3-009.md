# P3-009 — Model-family compiler + `ModelContextManifest`

## Source

- P3 `05` §5, `02` §6; DID v1.7 §8.19/§7.5

## Depends On

- P3-006

## Objective

Compile a plan into a portable request and build the manifest.

## Outputs

- `ModelContextPlan`, `PreparedModelTurn`, `PortableModelRequest`.
- `ModelContextManifest` + `ControlBasis` + `compiledRequestHash`.

## Must Hold

- Compiler cannot suppress `A0`–`A3` instructions.
- Manifest records instruction revisions/hashes + control basis.

## Must Not Decide

- No provider transport.
- No context selection policy change.

## Acceptance

- Manifest hash stable for identical inputs.

## Verification

```bash
pnpm test p3-compiler
pnpm check
```
