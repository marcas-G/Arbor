# P4-011 — `ToolInvocationStore` + intent-before-effect

## Source

- P4 `06` §1–§3; DID v1.8 §9.12

## Depends On

- P4-003

## Objective

Implement invocation persistence with the SideEffectSemantics snapshot.

## Outputs

- `ToolInvocationStoreLive` (`recordIntent`, `settle`, `consumeApproval`, `findUnsettled`).

## Must Hold

- Intent persisted before the effect; settlement persisted after.
- SideEffectSemantics snapshot stored.
- All methods require TransactionScope.

## Must Not Decide

- No Execution settlement policy.

## Acceptance

- Dangling intent detectable after a crash simulation.
