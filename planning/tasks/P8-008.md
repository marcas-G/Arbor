# P8-008 — Verifier spawn & drive (M-3 optional parent, WorkerDispatch Verifier, Yield, Attention)

## Source

- P8 `02` §1/§2/§3, `04` §4; DID v1.11 §10.4.1, G4/G5

## Depends On

- P8-003

## Objective

Execution-bound Verifier spawn and drive: M-3 `parentExecutionId` optional, the
`workerKind: "Verifier"` wiring, the three-layer isolation enforcement points,
Yield continuity, and settle-without-conclude behavior.

## Outputs

- VerificationRuntime spawn/drive wiring in the composition root.

## Must Hold

- **M-3**: `ExecutionBound.parentExecutionId` becomes optional — declared P2 inherited evolution (P6 `AdmitExecutionAuthority` origin-extension precedent); P2 payload + suite regression updated.
- Spawn: `AdmitExecution { _tag: "ExecutionBound", executionId: preallocated, workspaceId: owner snapshot, parentExecutionId: none, mission: verification digest }` via CommandGateway; verification-runtime deps = domain/ports/application only — no `execution-runtime`/`agent-runtime` imports (§10.4.1).
- WorkerDispatch `workerKind: "Verifier"` driven; P6 specialist spawn is the implementation template.
- **Three-layer isolation**: L2 canonical face = Record/Conclude only (P8-004); L4 Verifier context compiled from mission + artifacts + read-only observations — Producer Session content never copied in; L5 sandbox write surface restricted to temporary verification artifacts (blob prefix `verify:`, ArtifactMetadataRepository bound to verificationId); Producer formal artifacts/rows never writable.
- **Yield continuity**: Verifier may `Yield(waitSpec)` per P2 generic wait; Yield never produces verdict semantics.
- **Settle-without-conclude** → Verification stays Open + Attention recorded — no auto-Unknown, no auto-PASS ("no findings found" is neither); no P8 timers (durable timers belong to P2/P12).
- Settlement never writes the Verification aggregate directly — conclusions arrive only via ConcludeVerification.

## Must Not Decide

- No AdmitExecution semantics changes; no sub-execution nesting; no Attention presentation (P10).

## Acceptance

- Spawn payload shape, L5 write-attempt rejection, Yield round-trip, and settle-without-conclude → Open + Attention mechanically checked.
