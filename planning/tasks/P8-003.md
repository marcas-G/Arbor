# P8-003 — StartVerification handler (one-Open, owner snapshot, preallocated verifier id)

## Source

- P8 `01` §1/§6, `04` §3 (version binding), `02` §1 (preallocation); DID v1.11 G2/G4

## Depends On

- P8-002

## Objective

The `StartVerification` command handler with the frozen rejection table, one-Open
typed rejection, persisted owner snapshot, and the caller-preallocated
`verifierExecutionId` carried in the payload.

## Outputs

- Handler + `StartVerificationAuthority` projection.

## Must Hold

- Rejection table exactly `01` §1: `WorkNotFound` / `TerminalLifecycleMutation` / `RevisionConflict` / `InvalidVerificationMission` (mission structure error — never `AuthorityDenied`) / `AuthorityDenied` / `VerificationAlreadyOpen { workId }` (typed; v1.11 G2).
- **One-Open**: same `(workId, targetWorkRevision)` with an existing Open verification → typed rejection; orphan re-Start requires a prior Unknown(Orphaned) conclusion (G5 — path in P8-004).
- **Owner snapshot**: owning Workspace of the target Work at start time, persisted (G4); later retirement/move never auto-aborts or retargets.
- `verifierExecutionId` caller-preallocated in the payload — closes the spawn/backfill crash window by construction (replay in P8-006).
- **Cross-deliverable consistency**: every `targetDeliverables` entry's `sourceWorkRevision` must equal `targetWorkRevision`, else rejected; `targetArtifactVersions` always derived from deliverables (invariant 26 artifact part — never optional).
- **Executable mission** (runs tests / reproduces) → `targetEnvironmentRevision` required, read from `EnvironmentRevisionStore.current`; purely static review may omit (B-7).
- missionSnapshot = work.verificationMission snapshot + source overlay, same transaction (SD §9.4).

## Must Not Decide

- No spawn/drive semantics (P8-008); no consumer wiring (P8-006); no wake production.

## Acceptance

- Full rejection table, one-Open, and the revision/deliverable/environment bindings mechanically checked.

## Verification

```bash
pnpm test p8-start-verification
pnpm check
```
