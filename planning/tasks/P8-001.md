# P8-001 — P8 domain evolution (M-1 wake shape, M-2 mission schema, Orphaned, enums, event payloads)

## Source

- P8 `00` §迁移面 (M-1/M-2/M-4 declarations), `01` §1/§3 (rejection enums, conclusionReason), `03` §3 (wake shape), `04` §2 (structured criteria); DID v1.11 G1/G2/G5, §5.3

## Depends On

- P7-013

## Objective

Freeze the P8 vocabulary as code: M-1 `VerificationChanged` WakeCondition → work-level `{workId, targetWorkRevision}`; M-2 `VerificationMission.criteria` → structured `{criterionId, requirement, required}[]`; `conclusionReason: "Orphaned"`; new `CommandRejection` enums (`InvalidVerificationMission`, `VerificationAlreadyOpen`); payloads for `VerificationStarted` / `VerificationConcluded` / `WorkOutcomeAccepted` / `ExecutionSettled` (M-4: workId/workRevision/claimRef); the required-qualified verdict aggregation pure function.

## Outputs

- Domain ADT evolution (scheduler / verification / work / events) + persisted WaitSpec row migration notes.

## Must Hold

- **M-1**: the condition is exactly `{workId, targetWorkRevision}` (no verificationId key); P0 scheduler.ts type change + persisted WaitSpec row migration + P2/P3 suite regression updates green.
- **M-2**: criteria structured per v1.11 G1 (`{criterionId, requirement, required}[]`); P1 AssignWork payload/tests updated; P6 placeholder mission migration path declared (execution in P8-010).
- **Aggregation pure function** (`R = never`): any required Fail → Fail; no required Fail but required unresolved → Unknown; all required Pass → Pass; optional never blocks Pass.
- `conclusionReason: "Orphaned"` pairs only with verdict Unknown (G5).
- `VerificationAlreadyOpen { workId }` is a new enum — no P0-error reuse, no `ActiveExecutionConflict` reuse.
- `ExecutionSettled` payload carries `{workId, workRevision, claimRef}` (M-4 event-face enrichment; events.ts empty shell filled).
- Domain stays pure (`R = never`); no infrastructure imports.

## Must Not Decide

- No handler semantics; no DDL; no verdict semantics beyond v1.11; no WakeCondition/WakeReason beyond the M-1 shape.

## Acceptance

- Exhaustive switches compile; empty-shell lock-down tests updated for the four event payloads and both rejection enums; aggregation truth table mechanically checked.
