## Objective

Prove the lease/fencing/stop/settle/recovery contract end to end with deterministic tests.

## Outputs

- Integration tests for: expired-lease invalidation + late-write rejection; generation CAS; stopped + Normal vs QuiescenceControl; stale-generation settle; Yielded WorkWait + lost-wake-up; recovery settlement.

## Must Hold

- Deterministic ordering; no timing dependence.
- Tests assert frozen semantics, not implementation shape.
- No real Provider/Tool/HTTP.

## Must Not Decide

- No P3/P4 reconciliation tests.
- No P9 fault-injection suite.

## Acceptance

- Every lease/fencing/stop/settle/recovery case passes.
- A stopped valid worker can settle (QuiescenceControl) but cannot run a Normal mutation.
- Lost wake-up cannot strand a Work.
