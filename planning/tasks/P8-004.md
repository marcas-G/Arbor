# P8-004 — Record / Conclude handlers (verifier-only, aggregation, Orphaned path)

## Source

- P8 `01` §2/§3/§6, `04` §1/§2; SD v1.3 §9.6; invariant 26

## Depends On

- P8-002

## Objective

The two verifier-only command faces: `RecordVerificationEvidence` (append) and
`ConcludeVerification` (verdict + deterministic aggregation + the Orphaned
governance path).

## Outputs

- Handlers + `VerifierExecutionAuthority` exact-bound projection.

## Must Hold

- **Verifier-only authority**: `VerifierExecutionAuthority { verificationId, executionId }` exact-bound; any other submitter → `AuthorityDenied` (L2: these two commands are the Verifier's entire canonical mutation face).
- `RecordVerificationEvidence`: verification Open; evidence append-only, same evidenceId idempotent; **no domain event** (runtime record, DID §3.7 — do not add one).
- `ConcludeVerification` preconditions: Open; verifier authority; criteriaResults complete with every criterion bound to evidenceRefs (invariant 26); overall verdict must equal the required-qualified aggregation pure function (P8-001).
- **Orphaned path (G5)**: `conclusionReason: "Orphaned"` waives the evidence-completeness precondition; submitter = Parent Workspace governance-chain authority (explicitly not verifier-only); valid only with verdict Unknown; event payload carries conclusionReason; purpose is exclusively clearing the way for re-Start.
- **Verdict immutable** after conclude (P0 transition; PASS never re-judged FAIL).
- `VerificationConcluded` and wake production share one transaction (commit boundary declared here; wiring in P8-009).

## Must Not Decide

- No aggregation-rule changes; no evidence domain event; no settlement semantics (P8-008).

## Acceptance

- Authority violations, aggregation mismatch, Orphaned waiver scope, and verdict immutability mechanically checked.

## Verification

```bash
pnpm test p8-conclude
pnpm check
```
