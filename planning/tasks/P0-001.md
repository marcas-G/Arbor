# P0-001 — Repository skeleton & toolchain baseline

## Source

- DID §11 DID-10, P0 scope
- DID §14.1 Frozen technical baseline
- DID §14.2 Monorepo tool strategy
- DID §14.3 Root acceptance entry
- DID §10.1 Monorepo boundary
- `AGENTS.md` (hard rule 5)

## Depends On

None.

## Objective

Establish the pnpm workspace, TypeScript project-reference build, Biome,
and Vitest configuration that every later P0 task builds on, and place the
`@arbor/domain` package. No domain logic is implemented here.

## Inputs

- Existing root `package.json` (scripts already defined).
- Frozen baseline: Node `24.21.0`, TypeScript `7.0.2`, Effect
  `4.0.0-rc.115`, pnpm `12.4.2`, Vitest `5.0.1`, Biome `2.5.14`.

## Outputs

- `pnpm-workspace.yaml` declaring `packages/*`, `adapters/*`, `apps/*`
  (only `packages/domain` populated in P0; DID §10.1 has no `tooling/`
  workspace root).
- Root `tsconfig.base.json` + solution `tsconfig.json` using project
  references; `packages/domain/tsconfig.json`.
- `packages/domain/package.json` (`@arbor/domain`, ESM, `exports` map, no
  internal deps).
- `biome.json`.
- `vitest.config.ts` with workspace/project globs.
- **Frozen source/test layout**: domain source under
  `packages/domain/src`, domain tests under `packages/domain/test`.
- Architecture test home `tests/architecture/` (DID §10.1, §10.4.1).
- Removal of the placeholder flat `src/` and `tests/.gitkeep` layout.
- A VCS repository (`git init`) so commit provenance can be recorded
  (P0-018). This is a process artifact, not a design requirement.

## Must Hold

- ESM only; `tsc -b` build with project references.
- **Test files are part of a `tsc -b` project**, so type-level assertions
  in `packages/domain/test/**` and the architecture tests are actually
  typechecked. Without this, `@ts-expect-error` acceptance is vacuous.
- `@arbor/domain` declares **no** internal package dependency (§10.4.1).
- Package boundaries are enforced via `exports` + dependency declaration,
  not deep relative imports.
- Root scripts match §14.3 exactly:
  `build`, `typecheck`, `test`, `lint`, `format`, `architecture`, `check`.
- `pnpm check` = `lint && typecheck && architecture && test`.
- No Turborepo / Nx / Bazel / Prisma / ESLint+Prettier / Husky (§14.2).

## Must Not Decide

- No domain types, aggregates, or transitions.
- No persistence, adapters, or runtime packages.
- No architecture test *rules* beyond the placeholder entry (owned by
  P0-017).
- Do not change the frozen version pins.
- Do not add a second architecture-test root; `tests/architecture/**` is
  canonical.

## Acceptance

- `pnpm install` completes with a lockfile.
- `pnpm build` and `pnpm typecheck` succeed on the empty domain package.
- A deliberately wrong type in `packages/domain/test/**` makes
  `pnpm typecheck` fail (proves tests are typechecked).
- `pnpm test` runs Vitest and exits 0 (placeholder test present, or
  `--passWithNoTests`); Vitest exits non-zero with zero matching files.
- `pnpm lint` and `pnpm format` run under Biome.
- `pnpm architecture` resolves the architecture test entry under
  `tests/architecture/`.
- The flat `src/` scaffold no longer exists.
- `git rev-parse --is-inside-work-tree` succeeds.
- Environment meets §14.1 (this is the phase entry blocker; record the
  exact `node --version` / `pnpm --version` in the result file).

## Verification

```bash
node --version          # must be 24.21.0
pnpm --version          # must be 12.4.2
pnpm install
pnpm check
git rev-parse --is-inside-work-tree
```
