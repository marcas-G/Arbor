# P10-007 — Transcript production read path + Usage aggregation

## Source

- P10 `01` §1 (Transcript / Usage rows + derive inputs), P10 `05` §1 (TranscriptReq / UsageReq cores); SD §12.4 note, §10.2, §12.1, §7.7 (invariant 45)

## Depends On

- P10-003

## Objective

The first production read path over `session_entries` (Transcript, with
deterministic cursor paging) and the Usage aggregation over
`provider_turns.usage_json` (groupBy workspace / subtree / project),
wired into the Tree view's `usageSummary`.

## Outputs

- Transcript read path (session_entries + provider_turns + model_context_manifests) with cursor paging; Usage aggregation + Tree wiring; `p10-transcript-usage` suite.

## Must Hold

- Transcript = on-demand debug view, human-readable projection, **not truth** — never feeds cognition (SD §12.4 note, §10.2).
- Cursor paging per the frozen core: `TranscriptReq {workspaceId, sessionId?, cursor?, limit}` → `{entries[{kind, summaryRef, at}], nextCursor?}`; nextCursor semantics deterministic (replay-stable).
- Usage **observe-only (invariant 45)**: aggregation never influences budget or any mutation; `UsageReq {projectId, groupBy: "workspace"|"subtree"|"project"}` → `rows[{workspaceId, tokens, cost, turns}]`.
- Tree `usageSummary` populated from the same aggregates — single aggregation source, no second derivation.
- Read-only; watermark/lag carried per the port envelope.

## Must Not Decide

- No retention / paging-window policy decisions here (P10-009 projection-side retention); no transport paging (P12); no truth semantics for transcripts.

## Acceptance

- Paging round-trip with stable cursors over a seeded multi-session fixture; aggregate correctness mechanical (sums over usage_json); Tree usageSummary consistency assertion; observe-only snapshot green.

## Verification

```bash
pnpm test p10-transcript-usage
pnpm check
```
