# P2-012 — `WorkWaitStore` + `SchedulerTimerStore`

## Source

- P2 `02` §8, `04` §3.5–§3.6, `05` §2, §5–§6; DID v1.7 §8.16

## Depends On

- P2-004

## Objective

Implement durable WorkWait and scheduler timer stores.

## Outputs

- `WorkWaitStoreLive` (`upsert`, `findByWork`, `clear`, `listActive`).
- `SchedulerTimerStoreLive` (`schedule`, `due`, `cancel`).

## Must Hold

- `conditions_json` is a non-empty `WakeCondition[]`; empty rejected before write.
- `TimeReached` timers are durable rows; no in-memory timers.
- `clear` runs in the consuming transaction.

## Must Not Decide

- No wake-signal production (source phases).
- No runnability classification (P7).

## Acceptance

- Wait upsert/find/clear round-trips; empty conditions rejected.
- Due timers returned by `due(now)`; fired/cancelled timers removed.

pnpm test p2-work-wait
pnpm check
