# P4-014 — `patch` tool

## Source

- P4 `08` §3

## Depends On

- P4-012

## Objective

Implement the versioned `patch` tool.

## Outputs

- `patch` executor bound to the frozen schema; Idempotent semantics.

## Must Hold

- Same invocation key replay idempotent.
- Conflicting patch → ExpectedFailure.

## Must Not Decide

- No non-idempotent write semantics.

## Acceptance

- Replay does not double-apply; conflict is an ExpectedFailure.
