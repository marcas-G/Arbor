# P6-011 — SteerWork handler

## Source

- P6 `04` §2/§3; DID §12.10（SteerWork→WorkSteered）, §2.3; SD §7.3

## Depends On

- P6-001

## Objective

Implement the `SteerWork` command handler（Normal severity path）and the HumanInput channel into the target Workspace Inbox.

## Outputs

- Handler + rejection set + `WorkSteered` event payload.

## Must Hold

- Full precondition table of `04` §2; `CommandRejection.WorkNotFound` added as P6-frozen enum.
- semantic steer increments WorkRevision（revision 单调）; Normal steer never interrupts execution.
- HumanInput provenance is `AuthenticatedHuman`; sibling/child steer → `AuthorityDenied`.

## Must Not Decide

- No Critical wiring (P6-012); no CancelWork/CompleteWork; no severity auto-escalation.

## Acceptance

- Event carries from/to revision + severity; Normal steer adds no execution interruption（动作计数不变）.
