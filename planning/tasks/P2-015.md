# P2-015 — Recovery skeleton + `RecoveryController`

## Source

- P2 `06` (all); DID v1.7 §3.4, §6A.6, §12.11; SD v1.3 §10.6–§10.7

## Depends On

- P2-009
- P2-010
- P2-011
- P2-014

## Objective

Implement the deterministic Execution-boundary recovery pass.

## Outputs

- `RecoveryController` running the `06` §2 order (Execution boundary).
- `ReconciliationSource` stub (`[]`).
- DurabilityEnvelope declaration.

## Must Hold

- Invalidate expired leases; never settle on expiry alone.
- Settle only deterministic outcomes via `SettleExecution` with `RecoveryController` authority.
- No blind replay for uncertain cases; escalate / leave Active.
- Reconciliation content is a stub; unresolved side effects never settle to plain `Completed`.

## Must Not Decide

- No tool/provider reconciliation (P3/P4).
- No projection rebuild (P10).
- No fault-injection hardening (P9).

## Acceptance

- Expired lease invalidated; a late worker write is authoritatively rejected.
- Deterministic stop case settles via recovery authority.
- Uncertain case is escalated, not settled.
