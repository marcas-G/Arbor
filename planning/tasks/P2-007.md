# P2-007 — `FenceStopCheck` real implementation

## Source

- P2 `02` §4, `03` §4–§5, `01` §3; DID v1.7 §9.7

## Depends On

- P2-006

## Objective

Replace the P1 inert hook with the authoritative fence/stop implementation.

## Outputs

- `FenceStopCheckLive` evaluating the P2 predicate with `stopAdmission`.

## Must Hold

- Only evaluated for `ExecutionOrigin`.
- Fence invalid → `FencingRejected`.
- `NormalExecutionMutation` + `stop_requested_at != null` → `ExecutionStopping`.
- `QuiescenceControlMutation` / `StopControl` → `Pass` (fence still enforced).
- `Unclassified` on `ExecutionOrigin` is a defect.
- A valid generation is never returned `FencingRejected` merely for stop.

## Must Not Decide

- No default-allow.
- No boolean `stopAdmission`.

## Acceptance

- Invalid generation → `FencingRejected`.
- Stopped + Normal → `ExecutionStopping`; stopped + QuiescenceControl → `Pass`.
- Settled execution → `FencingRejected`.

```bash
pnpm test p2-fence-stop
pnpm check
```
