# P6-008 — SpecialistSettled → Inbox dedup, no Parent Session writes (D3)

## Source

- P6 `01` §3（D3 冻结约束）; P6 `02` §4; DID §5.4（at-least-once）

## Depends On

- P6-002, P6-007

## Objective

Route specialist settlement into the Parent Workspace Inbox projection with replay-safe dedup and wake.

## Outputs

- Settlement observer + Inbox admission path + wake signal emission.

## Must Hold

- Dedup key = `specialistExecutionId + settlementFingerprint`（fingerprint 由 settlement ADT 派生，确定性）; upsert-by-key.
- Replay（consumer 重投 / projection rebuild）→ Inbox 至多一条；重复 wake 无害.
- **任何路径不得写 Parent Session**（driver/consumer/recovery 一律禁止）.

## Must Not Decide

- No parent cognition injection; no correlation semantics beyond key.

## Acceptance

- Double-delivery test leaves exactly one Inbox entry; Parent Session entry count unchanged（机械断言）.
