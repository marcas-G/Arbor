# P3-005 — Instruction resolver + trust metadata

## Source

- P3 `02` §3–§4/§10; DID v1.7 §8.4A/§8.7

## Depends On

- P3-004

## Objective

Implement the deterministic instruction resolver and trust metadata.

## Outputs

- `ResolvedInstructionSet { effective, suppressed, conflicts, governanceIssues }`.
- `InstructionConflict` kinds.
- `InformationTrustMetadata` + `DataOnly` default.

## Must Hold

- Authority/capability resolution deterministic; LLM may only detect semantic conflicts.
- Unresolvable same-level canonical conflict → `GovernanceBlocked`.
- Only runtime-compiled canonical text may be `CanonicalInstruction`.

## Must Not Decide

- No silent authority promotion from model text.

## Acceptance

- Conflict kinds resolved deterministically; unresolvable → `GovernanceBlocked`.

```bash
pnpm test p3-resolver
pnpm check
```
