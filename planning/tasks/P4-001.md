# P4-001 — P4 package skeletons + harness wiring

## Source

- DID v1.8 §10.4.1, §11 P4; P3-018

## Depends On

- P3-018

## Objective

Create the P4 packages/adapters and wire the build/test harness.

## Outputs

- `packages/tool-runtime` skeleton.
- `adapters/sandbox-local` skeleton.
- `adapters/blob-local` skeleton.
- Root tsconfig references; architecture matrix keys.

## Must Hold

- `tool-runtime -> domain, ports`; `model-context !-> tool-runtime`; `agent-runtime !-> tool-runtime`; `adapters/* -> domain, ports`.

## Must Not Decide

- No behavior, no services, no DDL.
- No weakening of the matrix.

## Acceptance

- `pnpm build`/`pnpm typecheck` green.
- `pnpm architecture` recognizes the new packages.

## Verification

```bash
pnpm test p4-harness
pnpm check
```
