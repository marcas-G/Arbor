# P4-013 — `read` tool

## Source

- P4 `08` §2

## Depends On

## Objective

Implement the versioned `read` tool.

## Outputs

- `read` executor bound to the frozen schema; ReadOnly semantics.

## Must Hold

- Confined to admitted regions.
- Truncated observation + byte size.

## Must Not Decide

- No write effects.

## Acceptance

- Reads within region; out-of-region → Denied; retry allowed.
