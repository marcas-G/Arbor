# P2-010 — `StopExecution` handler

## Source

- P2 `01` §4, §6; DID v1.7 §3.4, §9.7

## Depends On

- P2-005
- P2-007

## Objective

Implement the `StopExecution` command handler (runtime control).

## Outputs

- `StopExecutionPayload` / `StopExecutionResult`.
- `makeStopExecutionHandler` with `StopExecutionAuthority` and `StopAdmission.StopControl`.

## Must Hold

- Sets `stop_requested_at`; emits `ExecutionStopRequested`.
- Idempotent on an already-stop-requested Active execution (no duplicate event).
- Settled execution → `TerminalLifecycleMutation`.
- Stop is not Work cancellation.
- Authority origins `System | ExecutionOrigin` only.

## Must Not Decide

- No quiescence reconciliation implementation (P3/P4).
- No `External` human stop.

## Acceptance

- Stop sets the fact and emits the event once.
- Second stop is idempotent.
- Missing execution → `ExecutionNotFound`.
