## Objective

- Payload fields exactly match P6 contracts (`01` §2/§3, `02` §2).
- `urgency` literal `"Normal"`; kinds limited to the four message kinds.
- Domain stays pure (`R = never`); no infrastructure imports.

## Must Not Decide

- No handler semantics; no DDL; no prompt text.

## Acceptance

- Exhaustive discriminated-union switches compile; constructing illegal variants fails typecheck.
