# P5-006 — Yield → WorkWait → wake → continuation

## Source

- P5 `04` §2; DID v1.9 §8.16, P2 `05`

## Depends On

- P5-005

## Objective

Wire Yield to durable WorkWait and wake-driven continuation.

## Outputs

- Yield settles Completed(Yielded); WorkWait registered in the same tx; a wake re-evaluates and admits a new Execution.

## Must Hold

- Work stays Open; no head-of-line stall.
- TimeReached via durable scheduler timers.
- Lost-wake-up protection exercised.

## Must Not Decide

- No dependency-aware wake production (P7).
- No in-memory timers.

## Acceptance

- Yield → wait row → wake → continuation on the same session.

```bash
pnpm test p5-yield-wake
pnpm check
```
