# P5-008 — Restart continuity (dispose/reconstruct)

## Source

- P5 `04` §4; DID v1.9 G5; P2 `06`

## Depends On

- P5-007

## Objective

Prove representative restart continuity on the same durable DB.

## Outputs

- Test: run slice, stop (dispose layers/close DB), reconstruct, resume same Work/Session.

## Must Hold

- P2 owns the recovery mechanism; P5 owns the acceptance proof only.
- No mid-transaction crash injection (P9).
- Same Work Open; same primarySessionId; entries intact.

## Must Not Decide

- No new recovery mechanism.
- No systematic fault injection.

## Acceptance

- After reconstruct, the loop resumes the same Work/Session with no duplicate Execution.

```bash
pnpm test p5-restart
pnpm check
```
