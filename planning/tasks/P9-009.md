# P9-009 — Tool four-tier injection (No.35/No.54) + D3

## Source

- P9 `02` §5 (T-tier rows, shared dangling-detection note, T4 no-path note), `04` §3 (expanded per-tier assertions), `02` §4 (D3); P4 `06` §2–§4/§6 (intent-before-effect, tiers, ReconciliationSource, ref enumeration), P4 `02` §5 (pipeline re-entry); SD §14 No.35/No.54; DID v1.11 §6A.7, §9.12

## Depends On

- P9-001, P9-002

## Objective

Crash injection between intent persistence and settlement across the four
`SideEffectSemantics` tiers, with dangling detection via `findUnsettled` /
the real `ReconciliationSource` and the tier-specific post-crash action
assertions.

## Outputs

- `p9-tool-tiers` suite.

## Must Hold

- Crash injected between intent persistence and settlement (intent-before-effect, P4 `06` §2, makes every dangling invocation visible); the `side_effect_semantics` snapshot drives classification (DID §9.12); the four tiers share the dangling-detection assertion and differ only in the permitted post-crash action.
- **ReadOnly**: dangling detected; safe retry / settle per actual outcome; no `OutcomeUnknown` required; retry re-runs the full pipeline (P4 `02` §5 — re-entry re-runs authority/resource checks).
- **Idempotent**: replay uses the same invocation key `(executionId, invocationId)`; assertion: replay yields **exactly one settlement row**; adapter probe observes **no duplicate external effect**.
- **Reconcilable**: reconcile-then-settle — the recovery enumerates the ref; the owning tool reconciles external reality BEFORE any replay decision (P4 `06` §4); ordering assertion: **no replay admitted before a reconcile result exists**.
- **NonIdempotent**: ambiguity → `OutcomeUnknown(ReconciliationRequired(refs))` (or stays Active/reconciling); **never automatic replay** (No.35); no second invocation row under the same key; no re-execute; the Execution must not settle plain Completed/Interrupted/Failed (P2 `06` §5).
- NonIdempotent additionally asserts **no path exists** from a dangling NonIdempotent intent to any settlement without reconciliation.
- **D3**: daemon-crash fixture with unsettled tool intent → dangling detected via `ReconciliationSource.pending` (real source — B-1 wiring); tier semantics apply; **never** blindly settled `Interrupted` (No.54; `04` §1 I-1).

## Must Not Decide

- No settle-rule changes; no tool external reconciliation logic beyond ref enumeration (the owning tool decides, P4 `06` §6); no new tiers; no OutcomeUnknown vocabulary for provider turns.

## Acceptance

- Four tiers + D3 mechanically checked (crash-injected class); no-duplicate-effect probe (Idempotent) and no-replay-before-reconcile ordering (Reconcilable) explicitly asserted.
