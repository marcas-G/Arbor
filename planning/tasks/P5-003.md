# P5-003 — `DirectiveUnsupported` + slice directive dispatch

## Source

- P5 `03`; DID v1.9 §8.15, G3

## Depends On

- P5-001

## Objective

Add the non-fatal `DirectiveUnsupported` result and dispatch the slice's directive set.

## Outputs

- `DirectiveUnsupported` type + driver dispatch for the supported set; unsupported → `DirectiveUnsupported` Observation.

## Must Hold

- `DirectiveUnsupported` is a directive execution result, not an `AgentDirective`/`DomainError`/`CommandRejection`/Execution failure.
- `ProposeChildWorkspace`/`SpawnSpecialist`/`DeclareDependency` → `DirectiveUnsupported`; never `AuthorityDenied`.
- No change to the `AgentDirective` set or Output Contract.

## Must Not Decide

- No P6/P7 directive semantics.

## Acceptance

- Unsupported directives yield `DirectiveUnsupported` and the loop continues.

## Verification

```bash
pnpm test p5-directive-unsupported
pnpm check
```
