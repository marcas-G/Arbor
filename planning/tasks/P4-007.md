# P4-007 — `InvocationApproval` + atomic consumption

## Source

- P4 `03` §4; DID v1.8 G2; SD v1.3 §8.4

## Depends On

- P4-003
- P4-006

## Objective

Implement Exact-Intent Approval validation + atomic single consumption.

## Outputs

- `InvocationApproval` store; `matchApproval` + `consumeApproval`.

## Must Hold

- Binding on tool/version/actionDigest/targetResources/controlBasisDigest/expiry.
- Atomic single consumption in the settlement transaction.
- Mismatch/expiry forces re-approval.

## Must Not Decide

- No approval production (deferred resolver).
- No fuzzy/once-style approval.

## Acceptance

- Two invocations cannot consume the same approval; mismatch → Denied.

## Verification

```bash
pnpm test p4-approval
pnpm check
```
