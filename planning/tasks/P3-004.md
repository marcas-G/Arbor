# P3-004 — Prompt Program contract artifacts + instruction model

## Source

- P3 `05` §1–§4; DID v1.7 §8.4/§8.5/§8.6

## Depends On

- P3-002

## Objective

Freeze the versioned Prompt Program contract artifacts and the instruction model.

## Outputs

- `PromptProgram`, `PromptSlot`, `PromptProgramFamily` (DID §8.4 P1–P14).
- Base Agent Protocol, Responsibility-bound Protocol, Work Execution Program, Compaction Program artifacts (revision/hash/slots/outputContract/evalSetRef).
- `InstructionFragment`, `AuthorityRole` A0–A6, `CompositionMode`.

## Must Hold

- Prompt text is a versioned contract artifact (C5).
- Precedence by authority/scope/composition, never text order.
- `ReplaceScope` only on `replaceable` slots.

## Must Not Decide

- No program text for feature-phase families.
- No authority-ladder change.

## Acceptance

- Every P3 program has revision/hash/slots/evalSetRef.
- `A0`–`A3` cannot be overridden by a skill/custom fragment.
