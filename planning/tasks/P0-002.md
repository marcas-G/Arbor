# P0-002 — Typed ID kernel

## Source

- DID §2.1 Typed IDs
- DID §2.2 ID rules
- DID Appendix A — ID Prefix Convention
- DID §14.5 completion criterion 2

## Depends On

- P0-001

## Objective

Implement nominal/branded typed IDs with runtime Schema codecs and prefixes
for every independent durable identity, such that IDs cannot be crossed at
compile time.

## Inputs

- Branded-type facility from Effect Schema (`effect` 4.0.0-rc.115).
- Prefix convention (DID Appendix A).

## Outputs

- One branded type + codec per identity:
  `ProjectId`, `WorkspaceId`, `WorkId`, `ExecutionId`, `SessionId`,
  `VerificationId`, `DependencyId`, `DeliverableId`, `MessageId`,
  `ArtifactId`, `DecisionId`, `PermissionGrantId`, `AcceptanceId`,
  `EvidenceId`, `MemoryId`, `CommandId`, `EventId`, `ProviderTurnId`,
  `ToolInvocationId`, `WorkerId`.
- Prefix mapping `prj_ / ws_ / wrk_ / exe_ / ses_ / ...` used by runtime
  validation and debug output, including `PermissionGrantId` → `pgr_`
  (DID v1.4 Appendix A).
- UUIDv7-style time-sortable generation for new IDs.

## Must Hold

- TypeScript nominal/branded types: passing a `WorkId` where a `WorkspaceId`
  is expected is a **compile error**.
- Runtime Schema codec validates the prefix and the underlying UUIDv7 shape.
- ID encodes no name, parent path, business location, or sequence.
- Entity state evolution never changes identity.
- Human-friendly display codes (e.g. `W-42`) are **not** IDs.
- ID generation is a pure function of explicitly provided time/entropy
  inputs; the domain never reads an ambient clock or RNG (`R = never`).

## Must Not Decide

- Do **not** create `AgentId`, `RootWorkspaceId`, or `PrimarySessionId`
  (§2.1). Root/Primary are relation roles, not entity types.
- Do not add ID types beyond §2.1 without a Design Gap.
- Do not couple IDs to persistence or runtime concerns.

## Acceptance

- All §2.1 IDs exist with brands and codecs.
- A type-level test fails to compile when two ID types are interchanged
  (e.g. via `@ts-expect-error`).
- Round-trip encode/decode preserves value; malformed prefix is rejected.
- No `AgentId` / `RootWorkspaceId` / `PrimarySessionId` symbol exists.

## Verification

```bash
pnpm typecheck
pnpm test ids
pnpm check
```

The `ids` suite must contain the type-level non-interchangeability test and
the codec round-trip / malformed-prefix tests. The type-level test only
counts if `packages/domain/test/**` is compiled by `pnpm typecheck`
(required by P0-001).
