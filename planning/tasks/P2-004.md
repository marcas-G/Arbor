# P2-004 — P2 DDL migrations

## Source

- P2 `04` (all); DID v1.7 §9.6–§9.8; P1 `04` §4

## Depends On

- P2-003

## Objective

Add migration `0002_execution_session_kernel` with the P2 tables and constraints.

## Outputs

- `executions` + partial unique active-main index.
- `execution_leases`.
- `agent_execution_state`.
- `session_entries`.
- `work_waits`.
- `scheduler_timers`.
- Migration registered in the adapter migration list (`user_version = 2`).

## Must Hold

- `binding_kind ∈ {workspace, execution_bound}`; partial unique only on `workspace` and `settled_at IS NULL`.
- CHECK constraints from `04` §3.1 hold (focus/binding/settlement consistency).
- Migration is additive, forward-only, single transaction; startup refuses `user_version > latest`.

## Must Not Decide

- No P3/P4/P8/P10/P11 tables.
- No modification of the P1 `0001_init` migration.

## Acceptance

- Fresh DB migrates to `user_version = 2`.
- Partial unique rejects a second active main; allows `ExecutionBound` rows.
- CHECK constraints reject inconsistent binding/settlement rows.

## Verification

```bash
pnpm test p2-ddl
pnpm check
```
