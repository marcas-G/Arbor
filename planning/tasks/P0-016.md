# P0-016 — C10 truth-table coverage & cross-aggregate invariant audit

## Source

- DID §12.11 C10 — Aggregate transition truth tables
- DID §14.5 P0 completion criteria 2–13
- DID §6.2 Enforcement Matrix, L1 rows

## Depends On

- P0-005 … P0-015

## Objective

Provide a **coverage audit plus cross-aggregate invariant suite** for the
§12.11 truth tables and §14.5 criteria. Per-task tests are authoritative
and are written failing-first inside each task (TDD); this task does not
retroactively introduce their invariants. It adds only the cross-aggregate
/ end-to-end invariant tests that no single aggregate task owns, and
mechanically audits coverage.

## Inputs

- All P0 domain types and pure transitions.
- The per-task test suites from P0-005 … P0-015.

## Outputs

- A **machine-readable coverage matrix** with one entry per §12.11 row and
  per §14.5 criterion 2–13, each `{ id, owningTask, testRef, status }`.
  `status` is `COVERED` only when `testRef` resolves to a real test.
- A `coverage` checker test that fails on any missing row or `UNCOVERED`
  entry.
- Cross-aggregate / end-to-end invariant suite covering only what no single
  aggregate task owns:
  - `CompleteWork` end-to-end binding: Work + Verification + Acceptance
    revisions agree (§3.6, §14.5 criterion 3).
  - `CancelWork` → `withdrawDependenciesOnWorkCancel` consequence.
  - Producer loss → `markUnfulfillableOnProducerLoss` consequence.
  - `RetireWorkspace` full precondition set.
  - Typed-ID non-interchangeability; no `AgentId`; command
    same-id/different-fingerprint rejection.
- Single-aggregate rows are owned by their tasks and referenced in the
  matrix, not re-tested here:
  - Execution binding ADT + `StopExecution` → P0-009.
  - `RecordVerificationEvidence` → P0-011.
  - Dependency "revise expected contract" → P0-012.
  - `GrantPermission` / `RevokePermission` → P0-015.
  - §14.5 criterion 7 (resource codecs/overlap) → P0-007.

## Must Hold

- Every legal transition has a positive test; every illegal transition has
  a negative test asserting a typed rejection.
- Tests assert **semantics**, not implementation shape.
- No test depends on SQLite, Provider, Tool, or HTTP.
- Pure tests only: no infrastructure, no clock, no randomness without a
  deterministic seed.
- The coverage matrix has no missing or `UNCOVERED` row at completion, and
  the `coverage` checker enforces this mechanically.

## Must Not Decide

- Do not modify domain semantics to make a test pass; a mismatch is a
  Design Gap or an implementation bug.
- Do not duplicate per-task invariant tests; reference them.
- Do not test persistence/transaction atomicity (P1).
- Do not test runtime recovery or fencing enforcement (P2/P9).

## Acceptance

- The coverage matrix is machine-readable and complete.
- The `coverage` checker fails on a missing/`UNCOVERED` row (verified with
  a temporary mutated fixture).
- Every §12.11 row and §14.5 criterion 2–13 has a `COVERED` entry.
- The cross-aggregate suite passes.

## Verification

```bash
pnpm test -- invariants
pnpm test -- coverage
pnpm check
```
