# P9-004 — Lease renewal loop (TTL/3) + soft release

## Source

- P9 `03` §1 (renewal loop, cadence convention, release); P2 `03` §2 (acquire/renewal CAS), §7 (LeaseLost handling), §8 (duration non-contract); `02` §3 (L2/L3 rows — asserted in P9-007)

## Depends On

- P9-001

## Objective

Close the missing production drive: the worker lease renewal loop (renewal
CAS every TTL/3 during a drive) and worker-initiated soft release at drive
end. Zero mechanism change — drives over the P2-frozen CAS semantics.

## Outputs

- Renewal loop in the worker drive path + soft release + `p9-lease-renewal` suite.

## Must Hold

- Renewal = CAS on `(worker_id, generation)` extending `expires_at`; **generation UNCHANGED by renewal**; no new execution lease row identity — only `expires_at`/`updated_at` advance (P2 `03` §2).
- Cadence convention frozen at **TTL/3**; the TTL value and absolute cadence are empirical (P2 `03` §8 keeps lease duration non-contract).
- Renewal success keeps ownership continuous — no generation bump, no re-acquire.
- Renewal failure (stale generation / no live lease) → the worker lost ownership: `LeaseLost` locally; the worker **must stop durable mutation and must not ordinary-retry** (P2 `03` §7); the authoritative rejection, if a write is nonetheless attempted, is `FencingRejected` / `LeaseFencingRejected`.
- A drive shorter than one TTL needs no renewal; the loop is bounded by the drive lifetime, not an independent daemon thread.
- Release (soft): worker-initiated CAS on `(worker_id, generation)` deleting the live lease row; **release never settles the Execution and never changes Work lifecycle** (DID §6A.6); lazy invalidation remains the only lease-expiry authority — release is an optimization, not a correctness requirement.

## Must Not Decide

- No lease CAS / release semantics changes (P2 `03` owns); no TTL numerics as contract; no distributed / multi-host drives (P12); no scheduler changes; no renewal-driven WakeCondition/WakeReason.

## Acceptance

- Successful renewal → fenced write commits, ownership continuous (generation asserted unchanged across renewals); failed renewal → durable mutation stops and no ordinary retry occurs — both mechanically checked.
