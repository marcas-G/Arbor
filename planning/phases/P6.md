## Goal

Deliver Responsibility-Tree formation and multi-Workspace coordination on top
of the P5 slice: first-layer formation behind a revision-bound human gate
(`RecordDecision` → governance fact → `CommandGateway` execution), autonomous
deep-layer formation, specialist spawn/settlement via Inbox with replay-safe
dedup, the four-kind communication protocol (Report ≠ Deliverable), structural
parent/child authority with validate-only capability ceiling, Normal/Critical
human steer with quiescence integration, and the four P6-owned versioned
Prompt Programs with behavioral evals.

## Included

- P6 payload ADTs (`ChildWorkspaceProposal`, `SpecialistSpec`, `OutboundMessage`,
  `GovernanceRequest` kinds) + `FormationProposalRecord` + `SpecialistSettled`.
- P6 DDL (formation proposal store, message store, inbox projection).
- First-layer gate: proposal admission, revision-bound `RecordDecision`
  (D1), Application consumer → `CreateChildWorkspace` / `AssignWork`.
- Deep-layer autonomous formation + execution-originated authority fact
  projection + capability-ceiling validate-only checks.
- `SpawnSpecialist` → `AdmitExecution(ExecutionBound)`; settlement → Inbox
  projection with dedup, Parent Session write forbidden (D3).
- `Communicate` → `SendMessage` → `MessageSent` → Inbox
  admission/promotion/consumption → wake; correlation/causation (D2).
- `RequestGovernance` minimal routing (FormationApproval, DecisionRequest).
- `SteerWork` handler; Normal (non-preemptive) vs Critical (quiescence) steer.
- Prompt Programs v1 with contractRevision/textRevision dual versioning and
  behavioral eval gate (D4).
- Acceptance stories A–F; architecture tests; P5 regression guard.

## Excluded

- Dependency coordination, `Deliver`, runnability reevaluation (P7).
- Verification / Acceptance / `CompleteWork` (P8).
- Authority Resolver / PermissionGrant semantics (deferred).
- Retire / Successor migration semantics.
- Projection UI (P10); worktree isolation (P11); production surface (P12).

## Frozen Decisions (from the P6 contracts)

- D1: `RecordDecision` binds exact formation proposal revision; approve is a
  governance fact only; execution happens afterwards via `CommandGateway`
  with deterministic command ids.
- D2: message kinds are Query/Reply/Report/DecisionRequest; `Report` ≠
  Deliverable and cannot satisfy any Dependency.
- D3: specialist settlement enters only the Parent Workspace Inbox projection
  (dedup key `specialistExecutionId + settlementFingerprint`); direct Parent
  Session writes are forbidden.
- D4: contractRevision (mandatory semantics; governance-gated) is distinct
  from textRevision (full text version/hash; every change reruns behavioral
  evals).
- Deep/first-layer split is a deterministic depth computation (S1.4).
- Critical Steer commits `WorkSteered` + `StopExecution` in one reliable
  commit boundary; Work stays Open.

## Must Not Decide

- No new formation/communication commands beyond the frozen set.
- No Dependency/Verification semantics.
- No Authority Resolver.
- No canonical writes outside `CommandGateway`.
- No prompt-text-only enforcement of hard invariants.

## Exit criteria

P6 is complete when all of:

1. `pnpm check` is green (lint + typecheck + architecture + test).
2. `ProposeChildWorkspace`/`SpawnSpecialist` no longer return
   `DirectiveUnsupported` (only `DeclareDependency` remains, P7).
3. Story A: stale-revision decision rejected; approve ≠ create observed;
   deterministic-command-id replay is idempotent.
4. Story B: deep-layer formation is gate-free; ceiling violations yield
   `AuthorityDenied` without failing the Execution.
5. Story C: specialist settlement lands in Inbox exactly once under replay;
   Parent Session entry count unchanged.
6. Story D: message arrival never preempts; Report produces zero Dependency
   side effects; correlation closes on Reply.
7. Story E: Normal steer does not interrupt; Critical steer quiesces the
   active main in one commit boundary; Work stays Open and self-resumes.
8. Story F: all four Program files carry contractRevision/textVersion/textHash;
   text bump without eval rerun is rejected by the verification gate.
9. P5 acceptance stories still pass (regression guard).
10. Architecture tests enforce P6 package edges.
11. No open P6 Design Gap.
