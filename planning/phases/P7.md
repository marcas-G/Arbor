## Goal

Deliver dependency/deliverable coordination on top of the P6 slice: the six
coordination commands with exact-bound authorities, the Deliver primitive
(five message kinds + ChildDelivered wake), classification as the single
runnability authority (superseding the P5 provisional source), the
event-driven P7 coordinator with a single SatisfyDependency command face,
wait-for graph deadlock attention (fact events, zero auto-mutation), and the
wake production/consumption pipeline.

## Included

- Domain evolution: five message kinds (Deliver), directive specs, event payloads.
- DDL: `dependencies` / `deliverables` / `deliverable_artifacts` (migration id 6) + repositories.
- Six command handlers + `DeclareDependency`/`ProduceDeliverable`/`Deliver`/`SatisfyDependency` directives.
- Deliver primitive wiring (SendMessage kind=Deliver preconditions, ChildDelivered wake).
- Dependency-aware `RunnableWorkSource` (classification single authority; blocking rule; P5 inherited evolution).
- Event-driven coordinator (project-scoped lookup — implementation choice; single command face).
- Wait-for graph + `DeadlockAttentionRequested` (liveness re-check set incl. Declare/WorkWait-upsert).
- Wake production (same-commit-boundary) + consumption routing + clearWorkWait wiring; composition upgrade to P7_MIGRATIONS (fixes P6-era P4_MIGRATIONS residue).
- Acceptance stories A–F; architecture tests; P5/P6 regression guard.

## Excluded

- Verification / Acceptance / `CompleteWork` (P8; satisfaction ⟂ quality — v1.10 G2).
- WorkWait/timer machinery & lost-wake-up protection (P2).
- Message/Inbox semantics changes (P6; Deliver is the v1.10-authorized kind expansion).
- Attention presentation/UI (P10); environment/git (P11); production surface (P12).

## Frozen Decisions (from the P7 contracts)

- Six commands; `DependencyContractRevised` + `DeadlockAttentionRequested` events (v1.10 G1/G4).
- Deliver is a communication/orchestration primitive — never a new canonical command; Deliver ≠ satisfaction.
- Classification is the single runnability authority; blocking Dependency = Unsatisfied ∧ active WorkWait(DependencyChanged(dep)); `decide()` renders, never blocks.
- Event-driven coordinator; lookup shape not contractual; both paths share one `SatisfyDependency` command and the authoritative matcher.
- Deadlock detection is deterministic; it emits facts and performs zero lifecycle mutations.
- Wake payloads live in the delivery record, not the P2-frozen WakeReason union.

## Must Not Decide

- No matcher/state-machine changes (DID §1.8/§12.11; P0 implementation reused).
- No scheduler decision-table changes (§8.18A).
- No P8 semantics; no P6 Message/Inbox semantics changes.
- No canonical writes outside `CommandGateway`; no project-full-scan freeze.

## Exit criteria

P7 is complete when all of:

1. `pnpm check` green.
2. No directive returns `DirectiveUnsupported` anymore (the P5 table is fully retired).
3. Six commands enforce their frozen rejection sets; CAS first-winner + typed rejection under concurrent satisfaction.
4. Story B: coordinator auto-satisfies via matcher; replay idempotent; matcher-negative leaves state unchanged.
5. Story C: Deliver lands in parent Inbox, emits ChildDelivered wake, satisfies nothing.
6. Story D: revise never reinterprets old satisfaction; producer-loss batch transitions fire end-to-end.
7. Story E: wait-cycle emits `DeadlockAttentionRequested`; zero lifecycle mutation; declare-then-yield cycles detected at the second WorkWait upsert.
8. Story F: classification matrix (wait/dependency combinations) — decide() output equals classify for all cells.
9. Classification replaced source passes the updated P5 suite; P6 suites unchanged-green.
10. Architecture tests enforce P7 module placement; composition uses P7_MIGRATIONS.
11. No open P7 Design Gap.
