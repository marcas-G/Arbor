## Goal

Implement the P2 Execution / Session Kernel: durable Execution admission
(`WorkspaceMain` + `ExecutionBound`), Lease / Fencing with authoritative
same-transaction generation checks, `AgentExecutionState`, Session entry
append / epoch, the deterministic `ExecutionScheduler` with durable `WorkWait`
+ wake/timer and lost-wake-up protection, a minimal `ExecutionDriverPort` +
Fake Driver with execution-wide Runtime Safety gating, and the deterministic
recovery skeleton with `RecoveryController` settlement.

## Included

- `adapters/persistence-sqlite`: `executions`, `execution_leases`,
  `agent_execution_state`, `session_entries`, `work_waits`, `scheduler_timers`.
- `packages/ports`: P2 port contracts.
- `packages/execution-runtime`: `ExecutionRepository` usage, `LeaseService`,
  `FenceStopCheck` impl, `ExecutionScheduler`, `RecoveryController`,
  `AdmitExecution` / `StopExecution` / `SettleExecution` handlers.
- `packages/agent-runtime`: minimal skeleton (driver seam; real loop is P3).
- `packages/testkit`: `FakeDriver`, in-memory doubles.
- `adapters/worker-local`: local `WorkerDispatchPort`.
- P1/P0 artifact evolution (`RecoveryController`, `ExecutionNotFound`,
  `stopAdmission` ADT, `CommandAuthorityFact`, `FenceStopCheck` signature).
- Lease/fencing/stop/settle/recovery tests; architecture tests.

## Excluded

- Real Provider / Model Context / Agent loop (P3).
- Tool runtime / sandbox (P4).
- Specialist spawn / delegation semantics (P6 delegation, P8 verifier).
- Full Work runnability / dependency reevaluation (P7).
- `RecordEnvironmentChange` (P11).
- Projection / UI (P10); systematic fault-injection hardening (P9).

## Frozen Decisions (from the P2 contracts)

- Command-specific `VerifiedRuntimeCommandAuthority` (Admit/Stop/Settle);
  runtime origins only (`System`, `ExecutionOrigin`, `RecoveryController`);
  External human admit/stop deferred to the Authority Resolver phase.
- `NormalExecutionMutation` / `QuiescenceControlMutation` classify
  **Execution-originated** mutations only; `SettleExecution` ExecutionOrigin
  path is quiescence-control (admissible after stop, still fenced);
  `stopAdmission` is an explicit ADT (never a boolean).
- `AdmitExecution` supports `WorkspaceMain` (snapshot `primarySessionId`,
  one-active-main) and `ExecutionBound` (atomic Execution + `ExecutionScoped`
  Session); IDs caller-preallocated; no specialist concurrency limit.
- Lease = expiry + monotonic generation; authoritative fence check shares the
  mutation transaction (no TOCTOU); worker crash / lease expiry never settles.
- `ExecutionScheduler` is deterministic; P2 owns durable `WorkWait` +
  timer/wake + lost-wake-up; P7 owns runnability; source phases own wake
  signals.
- `ExecutionDriverPort` + `FakeDriver`; P2 owns execution-wide Runtime Safety
  gating; P3 reports turn/tool activity.
- `RecoveryController` settles deterministically; reconciliation content is
  P3/P4; P2 ships a stub.
- No new Domain Event types; no Session Domain Event; no durable `Pending`.

## Must Not Decide

The implementation agent MUST NOT:

- change frozen DID / P1 / P2 contract semantics;
- add commands, tables, lifecycle states, event types, or error tags not in the
  contracts;
- introduce a generic `SystemAuthority` / `ExecutionAuthority` category;
- admit `External` human admit/stop before the Authority Resolver phase;
- make `stopAdmission` a boolean or infer it from the command type;
- let a Worker-originated settlement bypass authoritative fencing;
- add specialist concurrency limits or spawn semantics;
- implement full runnable/dependency reevaluation (P7);
- use a transaction-external fence pre-check as final authority;
- use in-memory timers for `TimeReached`;
- implement `RecordEnvironmentChange` (P11);
- weaken `BEGIN IMMEDIATE` / `synchronous = FULL`.

## Exit criteria

P2 is complete when all of:

1. `pnpm check` is green (lint + typecheck + architecture + test).
2. P2 DDL migrates; `executions` / `execution_leases` /
   `agent_execution_state` / `session_entries` / `work_waits` /
   `scheduler_timers` exist with the frozen constraints.
3. `AdmitExecution` / `StopExecution` / `SettleExecution` match `01`
   payload/result/rejection/event and the command-specific authority rules.
4. Lease/fencing: expired-lease invalidation, generation CAS, same-transaction
   authoritative fence, `FencingRejected` vs `ExecutionStopping`.
5. `ExecutionScheduler` implements the §8.18A decision table over
   `RunnableWorkSource`; durable `WorkWait` + timer/wake + lost-wake-up.
6. `ExecutionDriverPort` + `FakeDriver` + `RuntimeSafetyGate` present; safety
   `Stop` yields `Interrupted(RuntimeSafetyStop)` with Work Open.
7. Recovery skeleton: expired-lease invalidation, unsettled detection,
   `RecoveryController` settlement, reconciliation stub, declared
   `DurabilityEnvelope`.
8. Architecture tests enforce the new package edges (DID §10.4.1).
9. No open P2 Design Gap.
