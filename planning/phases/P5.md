## Goal

Deliver a minimal runnable `apps/single-workspace` composition root plus a
deterministic end-to-end acceptance suite proving a long-lived Workspace Agent
completes Work across multiple Executions, Session continuation, Tool effects
and a real restart — emitting a `CompletionClaim` while the Work stays `Open`.

## Included

- `apps/single-workspace` composition root (Layer graph wiring P1–P4).
- Provisional single-workspace `RunnableWorkSource` implementation.
- `DirectiveUnsupported` directive execution result + slice dispatch.
- Multi-turn Session continuity, Yield → WorkWait → wake, CompletionClaim.
- Representative restart-continuity proof.
- The single full vertical-slice acceptance story.
- Architecture tests for `apps/*`.

## Excluded

- Verification / Acceptance / CompleteWork (P8).
- Dependency coordination + full runnability (P7).
- Multi-workspace formation / delegation (P6).
- Systematic fault-injection hardening (P9).
- Advanced environment / worktree isolation (P11).
- Production daemon/CLI surface.

## Frozen Decisions (from the P5 contracts)

- P5 is integration only: no subsystem redesign.
- P5 deliverable = minimal runnable `apps/*` composition root + deterministic
  e2e acceptance suite (not test-harness-only; not a production daemon).
- Provisional `RunnableWorkSource` implements the **existing P2 port**; it does
  not define global runnability; P7 supersedes it.
- `DirectiveUnsupported` is a directive execution result / model-visible
  observation — not an `AgentDirective`, `DomainError`, `CommandRejection`, or
  Execution failure.
- `CompletionClaim` settles the Execution only; Work stays `Open`; P8 owns the
  Verification/Acceptance chain.
- P5 owns only the representative restart-continuity proof; P2 owns the recovery
  mechanism; P9 owns systematic hardening.
- Deterministic Fake Provider is sufficient; real provider is non-gating.

## Must Not Decide

- No new subsystem semantics or ports.
- No `ProposeChildWorkspace` / `SpawnSpecialist` / `DeclareDependency` behavior.
- No Verification/Acceptance/CompleteWork.
- No global runnability or dependency graph.
- No recovery-mechanism change; no fault injection.
- No canonical writes outside `CommandGateway`.

## Exit criteria

P5 is complete when all of:

1. `pnpm check` is green (lint + typecheck + architecture + test).
2. `apps/single-workspace` builds and runs the slice against a durable DB.
3. The provisional `RunnableWorkSource` drives the P2 scheduler table.
4. Unsupported directives yield `DirectiveUnsupported` (non-fatal) without
   `AuthorityDenied` or Execution failure.
5. Multi-turn Session continuity holds across Executions (fixed
   `execution.sessionId`).
6. Yield → durable `WorkWait` → wake → continuation works.
7. CompletionClaim durably settles the Execution as `Completed(CompletionClaimed)`
   with the Work remaining `Open`.
8. Restart continuity holds (dispose/reconstruct on the same DB).
9. The full vertical-slice acceptance story passes deterministically.
10. Architecture tests enforce `apps/*` edges (Composition Root only).
11. No open P5 Design Gap.
