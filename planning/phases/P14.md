## Goal

人 ↔ Root Workspace 的 chat-first 对话面：`SubmitHumanMessage` → durable
pending → deterministic trigger → `AdmitExecution(WorkspaceMain,
focus=Coordination)` → 既有 agent 链 → `QueryCompleted` → transcript
Human/Assistant turn。**不发明 Chat Runtime**。
