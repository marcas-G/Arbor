## Goal

Land the UI-facing projection layer over **existing frozen semantics**
(zero mechanism change): the authoritative view inventory as queryable read
models (`01`), the Attention read-model with GAP-01 closure (`02`),
EffectiveFacts as the single shared canonical-state-derived projection with
the GQ5 freshness discipline (`03`), at-scale business-projection rebuild
(GQ2 handover from P9, `04`), the HumanInterventionApplied durable audit
fact with the P6 WorkSteered back-fill (GQ7, `06`), and the
message-mediated Query + user-action surfaces (GQ4/GQ6, `05`) — delivered
as the transport-neutral `api-contracts` package P12 binds to.

## Included

- View inventory realization (`01`): Tree (Workspace Summary / Project Overview as aggregated Tree renderings), Attention, Workspace Detail (⑥ = audit timeline from domain_events; Memory/Decisions store deferred), Current Work, Verification, Dependency, Transcript (first production read path over session_entries), Usage (observe-only), Inbox view; WorkspaceStatus exhaustive label map frozen from SD §12.2 text (incl. `retired`); Search deferred with recorded rationale.
- `api-contracts` package (deps: domain only) + `ProjectionQueryPort` signature freeze + per-view request/response cores + freshness watermark/lag/barrier types (`05` §1).
- `projection-runtime` package (deps: domain, ports) — read-only derive over canonical tables + journal; never participates in authority (§10.4 hard rule).
- Attention read-model (`02`): six frozen fact sources → severity → target; read-side dedup by frozen identities; subtree bubbling (context never copied upward); GAP-01 `WaitingOnVacantProducer` on-read derived view (¬Retired predicate; zero runtime mutation).
- EffectiveFacts (`03`): P10-owned materialization (incremental via generic consumer + on-read derive for joins) and query; P3 Context Builder consumes it (no second derivation, GQ2); monotonic watermark + observable lag + explicit `FreshnessRequirement` barrier (`{minWatermark}` | `{maxLag}` contract-level extension); no implicit RYW.
- HumanInterventionApplied (`06`): payload `{actor, targetWorkspaceId, summaryRef, occurredAt, kind}`; same-transaction emission on SteerWork (with WorkSteered P6-shape back-fill — inherited evolution) and the four human-originated governance commands (human-principal branch only); Stop branch dormant wire-only until the P12 resolver; consumption = bubbling + audit timeline.
- User-action surfaces (`05` §2): message-mediated Query (P6 channel → workspace-side P14 Execution-bound read-only execution → result Message/Inbox back-flow), Steer, Stop-request (resolver-gated, not implemented), Governance Change entry — all via `CommandGateway`.
- Rebuild at-scale (`04`): incremental checkpoints, projection-side retention (journal horizon untouched), orchestration (startup after nine-step step 8 / operator / drift-forced reset; P9-closure floor−1 rewind consumed unchanged; EffectiveFacts → raw fact views → Attention last), RB-4 query correctness; Inbox state-reconciliation audit face.
- Acceptance Stories A–G; P10 architecture tests; P5–P9 regression guards.

## Frozen Decisions (from the P10 contracts / GQ1–GQ7 + GAP-01)

- **GQ1**: SD view inventory is authoritative (Search/Summary/Overview/Inbox all P10); WorkspaceStatus labels frozen from SD §12.2 text — no invented labels; Summary/Overview realized as aggregated Tree renderings, no separate model (`01`).
- **GQ2**: EffectiveFacts = the single shared canonical-state-derived projection; P10 owns definition/materialization/freshness/query; P3 consumes — it must not re-derive a second copy (`03`).
- **GQ3**: P10 owns the Attention read-model (source→severity→target→bubbling→dedup); upstream produces facts only; **never auto canonical mutation**; disposition is a human/parent governance command (`02`).
- **GQ4**: external Stop authority resolver = P12 (inherited clarification of P2 `01`); external AdmitExecution likewise resolver-gated; P10 exposes request/control surfaces only and never calls either directly (`05` §2).
- **GQ5**: freshness = monotonic watermark + observable lag + explicit `FreshnessRequirement` barrier; **no implicit RYW**; `{maxLag}` is a contract-level extension of the barrier (a watermark expressed as acceptable lag; same mechanism, no new semantics) (`03` §2).
- **GQ6**: P10 = programmatic projection/query + UI-facing view semantics; P12 = transport shells that render `api-contracts` DTOs and forward commands without reinterpreting view semantics (`05` §3).
- **GQ7**: HumanInterventionApplied durable audit fact `{actor, targetWorkspaceId, summaryRef, occurredAt, kind}`, emitted in the same semantic transaction by human-originated canonical commands; P6 WorkSteered path back-filled as **inherited evolution** (the empty-shell events were the implementation deviation, DID v1.13 G7) (`06`).
- **GAP-01**: `WaitingOnVacantProducer` canonical-state-derived Attention view — `dependencies(Unsatisfied ∧ WorkspaceBound) × works(no Open Work) ∧ ¬Retired`; zero runtime mutation; may not be silently descoped (`02` §1, `planning/gaps/P7-GAP-01.md`).
- Deadlock severity: every emitted `DeadlockAttentionRequested` fact renders **Action Required** (No.42 project-idle gate — no conditional branch exists by frozen semantics) (`02` §1).
- Rebuild rewind: the P9-closure corrected form **floor−1** (DID v1.12 G2a) is consumed unchanged — a return to P1 `05` §6 full-replay semantics; P10 changes nothing further (`04` §1).
