## Goal

Systematize fault injection over **existing frozen semantics** (P2 owns the
recovery mechanism, P1 owns the command-transaction matrix, P5 owns the
representative restart proof): close the two recovery-visibility gaps
(B-1 real ReconciliationSource wiring + durable escalation facts; B-2
completion-fact settle), wire the missing production drives (recovery/sweep
triggers T1–T4, lease renewal loop, durable timer re-fire, consumer offsets),
land the GQ4 unsettled-ProviderTurn recovery face, and assert all nine
injection surfaces with the GQ5 guarantee-class discipline — zero mechanism
change.

## Included

- Fault-injection harness (process/daemon/worker kill — real termination preferred, full layer dispose/reconstruct as CI approximation; fiber interrupt; transaction fault modes via `faultingTransaction` extension) + guarantee-class labeling + p9-* suite skeleton (`02` §0/§11).
- B-1 (phase-scoped closure, not a Design Gap): composition root binds `ReconciliationSourceLive`; escalation → durable Attention facts (dedup `executionId + invocationRefs fingerprint`); I-1..I-3 gate.
- B-2: durable completion fact settles the corresponding Completed form (RecoveryController path, deterministic commandId).
- Trigger surface (GQ3): T1 startup full pass, T2/T3 single-flight sweeps with the frozen hook set (a–c), T4 pre-dispatch fence predicate only.
- Lease renewal loop (TTL/3 convention) + soft release; durable timer re-drive (fire + clear in one transaction).
- Injection matrix rows W / R / L / D / T / PD / CC / WF / DF / PR / PB — every row ≥1 mechanical case with its guarantee class.
- GQ4 face: disconnect mapping onto existing `ProviderFailureKind` + unsettled-ProviderTurn resume (same Turn, new Attempt, turnNo unchanged).
- Consumer offset wiring (P7 coordinator + P8 consumers A/B onto P1 consumer infra) + CC-1..CC-6; generic rebuild RB-1..RB-5 (GQ2 P9 face) + durability-asserted evidence protocol (GQ5).
- Acceptance stories A–G; P9 architecture tests; P5/P6/P7/P8 regression guards.

## Excluded

- At-scale business-projection rebuild (P10, GQ2); Attention presentation (P10); recovery daemon/composition surface (P12); environment/git (P11); X1–X11 (superseded archival, GQ1); new failure taxonomies; settle-rule changes; dispatch ack/durable-dispatch-record surfaces; fault-injecting SQLite adapter.

## Frozen Decisions (from the P9 contracts / GQ1–GQ5)

- **GQ1**: X1–X11 are superseded / non-normative archival; P9 never cites them — assertions cite C-series rows, §14 invariants, and frozen phase contracts only (`02` §0).
- **GQ2**: P9 owns generic recovery/rebuild semantics; P10 owns concrete business projections / at-scale rebuild (`02` §10, `05` §3).
- **GQ3**: recovery triggers = T1 startup full pass + T2 periodic / T3 event-triggered sweeps + T4 targeted pre-dispatch fence check; **T4 never runs the nine steps**; recovery pass triggers produce no organizational mutations (`01` §3, `03` §2).
- **GQ4**: no new provider failure tag — connect-phase failure → `ProviderUnavailable`, post-stream → `StreamInterrupted`; P9 owns unsettled-ProviderTurn crash recovery (same ProviderTurn, new ProviderAttempt, turnNo unchanged) (`02` §6, `04` §2).
- **GQ5**: no fault-injecting SQLite adapter; real process/daemon/worker crash injection; power-loss/WAL semantics proven via SQLite durability contract + declared DurabilityEnvelope + reopen/integrity evidence; **crash-injected vs durability-asserted guarantees explicitly distinguished** (`02` §0/§12, `05` §4).
- ReconciliationSourceStub replacement is a **phase-scoped closure**, not a Design Gap (`01` §1, `04` §1).
- Renewal cadence convention frozen at **TTL/3**; TTL / sweep interval / retry / batch numerics are empirical, task-level (`03` §1; scope-extraction §C).
- Poison classification (`05` §2 CC-4): typed `DomainError` rejections are NOT poison; deterministic defects ARE; transient operational failures abort-and-retry — never dead-letter.
- RuntimeSafetyGate stays in-process — maintained, not upgraded; dirty-restart assertions must not assume counter continuity (`03` §4).
- Naming (B-10): Phase P9 ≠ DID §8.4 "P9 Verification Program" (shipped with P8); artifacts say "Phase P9 / recovery hardening".
