## Goal

浏览器瘦客户端 `apps/web`（Vite + React）：渲染 9 个 frozen view DTO、
WS invalidation/refetch、7 个 Human-actionable governance 命令表单，
生产态由 single-workspace daemon 同源托管。角色冻结：
**Projection Renderer + Command Initiator**。

## Included / Excluded

Included: `apps/web` 全部；TR-W1（WS invalidation 帧服务端+客户端）；
TR-W2（static 同源托管）；design token system；UI command catalog；
架构/render/Problem/e2e 测试；root 编排接入（build+test 并入 `pnpm check`）。
Excluded: chat-first 对话面（P14+）；Search（out-of-v1）；任何 view/command/
authority 语义变更；`SelectCurrentWork` 人工选择；`SendMessage` chat 解释。
