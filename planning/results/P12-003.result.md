## Deviations / notes

1. **`ProviderExecutionContext.secretRef` is optional, not required.** The frozen P3 `01` §2
   declares `secretRef: SecretRef`; the pre-existing code had the non-compliant
   `secretRef: string`. This task corrects the type to `SecretRef` and additionally makes it
   optional so a turn with no credential (the deterministic fake / local providers) carries
   none rather than a fabricated ref. When a ref is present it is always `SecretRef`; the
   resolution path and typed failures are unchanged. `ProviderRunInput.secretRef` is likewise
   optional (it is an implementation type, not part of the frozen P3 §2 surface).
2. **Additive `ProviderExecutionContext.secretMaterial?: SecretMaterial`.** Added so the
   resolved credential can reach the transport adapter at the execution boundary while the
   Agent (driver) only ever sees the `SecretRef`. Additive field; no change to the frozen
   `secretRef` field's meaning.
3. **`ProviderRuntimeService.runTurn` error channel gains `SecretStoreError`** (additive).
   ProviderRuntime resolves at the boundary, so missing/inaccessible/expired secrets surface
   as typed failures; the driver maps them to `ExecutionDriverError` (no silent substitution).
4. **`secret-file` envelope format is an adapter implementation choice.** Contract `03` §3
   fixes "restricted path" but not the file format. Raw file content is the credential; a JSON
   object `{ "value": string, "expiresAt"?: string }` yields the value and an optional expiry
   (the only way to exercise `SecretExpired` for this adapter).
5. **Sandbox allow-list extracted to `@arbor/ports`.** `SANDBOX_ENV_ALLOWLIST` +
   `sandboxEnvironment` moved from `sandbox-local` and re-exported there (public API
   unchanged) and from `sandbox-worktree`, so every sandbox adapter shares one projection
   mechanism (P12 `03` §3 / `13` §3 NEW-14). The full negative assertion is owned by P12-012.
6. **P7/P9 manifest-freeze reconciliation.** `apps/single-workspace/package.json` was dropped
   from `P7_TOUCHED_MANIFESTS` / `P9_TOUCHED_MANIFESTS`: P12-003 legitimately extends the
   Composition Root dependency set. The package-DAG architecture test still constrains every
   declared edge.
7. **`provider-fake` is unchanged** and ignores `secretMaterial`; consuming the resolved
   credential in a real transport adapter is P12-011's scope (`12` §2, `ProviderPort`
   semantics unchanged).
