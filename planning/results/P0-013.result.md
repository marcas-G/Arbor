- Fingerprint stable under key reordering; differs under payload change and
  command-type change.
- `resolveIdempotency`: new id → `New`; same id + same fingerprint →
  `SameLogicalRequest`; same id + different fingerprint → `IdempotencyConflict`.
- `CommandEnvelope` has no trusted-origin field (`origin`, `principal`,
  `executionId`, `fencingGeneration`) — field-presence test.
- `CommandSubmissionContext` is exhaustive (`External` / `ExecutionOrigin` /
  `System`) with a `never` default.
- `CommandAttempt` is a `(commandId, attemptNo)` local ordinal.
- `CommandResolution` is `Committed | TerminalRejected`.
- No infrastructure import in the domain package.
