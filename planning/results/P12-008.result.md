## Deviations / notes

1. **D1 mechanism — the attempt-ordinal channel (B-4).** `ProviderRuntimeLive`
   owns transient transport retries internally (DID §6A.9), so the driver cannot
   see them at the ProviderTurn boundary. Rather than widen `ProviderRuntime`'s `R`
   channel with `RuntimeSafetyGate` (not authorized by the frozen contract), the
   real Turn-local attempt ordinal is surfaced on the **result**:
   `ProviderRuntimeService.runTurn` returns `ProviderRunResult { events, attemptNo }`,
   and the driver reports `attemptNo` as `RuntimeSafetyObservation.retryCount`
   at the provider-call completion boundary. Retry never creates a new
   `ProviderTurn`; `retryCount` is the only channel (P12 `08` §7 D1). The begin
   boundary still reports `retryCount: 0` (first attempt / new operation), and the
   completion boundary reports the final real ordinal only when the turn was
   lease-scoped or actually retried, so a clean non-lease-scoped turn adds no
   extra admission. The completion observation is tagged `inFlight: "end"`, which
   is never a D4 turn boundary.
2. **D3 depth convention.** A ProviderTurn reports `chainDepth: 0` (the chain root);
   a ToolInvocation / SpecialistAction reports `chainDepth: 1`. `chainDepth: 0`
   resets the chain. This makes D3 observable and trippable through the real driver
   with a single top-level tool call.
3. **`observedAt` uses the wall clock** (`new Date().toISOString()`) rather than the
   `Clock` port, to avoid widening the driver's `R` channel and cascading layer
   composition changes. D6 determinism is preserved by the direct gate tests, which
   pass explicit `observedAt` timestamps.
4. **D5 begin/end brackets the provider call.** Tool/specialist boundaries report
   D3 chain depth (one admission each); the D5 in-flight gauge is bracketed
   (begin/end) at the provider call. The D5 mechanism (including lease scoping and
   call-completion reset) is directly evidenced (tests 9–10).
5. **Durable progress definition.** The driver sets `durableProgress` from a
   journal-recorded action settlement since the previous turn boundary (P12 `08`
   §5). The gate only counts the boolean (`R = never`); the D4 counter is
   in-process (RG-11 / P9 `03` §4).
6. **TR-10 filed as an inherited P2 evolution.** The only P2 gate port change is the
   additive optional observation argument; the two-argument call is unchanged and
   P2 gating ownership is not reopened. No `docs/design/**` file was modified.
7. **No `Clock` dependency added** to `@arbor/agent-runtime`; no new package edges;
   package-DAG and P7/P8/P9 manifest-freeze architecture tests remain green.
