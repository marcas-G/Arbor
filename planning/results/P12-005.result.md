## Deviations / notes

1. **Internal capability location (TR-1).** The contract says advancement is reachable only via an "internal, non-exported capability". It is declared in `adapters/persistence-sqlite/src/environment-advancement.ts` and deliberately **not** re-exported from the adapter `index.ts` (nor present anywhere on the `ports` surface). A ports-internal module could not be consumed by the adapter because the ports package exposes only its root export; the public mechanical guarantees the contract names — no `advanceAnchor` on the ports public surface, no observation-side advancement import — are fully asserted.
2. **REC remains the sole production advancement authority.** The governed `RecordEnvironmentChange` path inlines its CAS (P11 result deviation #4); it was not refactored (no behavior change, no scope creep). The internal capability is the store-level CAS face used by the revision-algebra / persistence-boundary suites.
3. **TR-2 encoding scope.** The structured blob keeps the `p11-snapshot-v1` header and JSON project-id line (so existing malformed-blob tests remain meaningful) and encodes each region as one JSON object. The fingerprint recipe (`canonicalSnapshotBytes`) is intentionally unchanged: the region-encoding/fixture re-baseline is `09` §4.1's task. The blob bytes are therefore no longer byte-identical to the fingerprint input bytes, but round-trip fingerprint stability is preserved (asserted).
4. **Restore drill mechanics.** Backup via `VACUUM INTO`; restore copies the backup to a separate path guarded by `assertRestoreIsolation`; reconciliation advances the lease generation and clears the incarnation, then verifies zero pre-restore matches. The drill imports no runtime/worker package (mechanically asserted). `measuredRto`/`measuredRpo` floor to whole seconds (hence `PT0S` on a fast drill), still `<=` the declared RTO/RPO.
5. **`pnpm check` flakiness.** On this host the default-parallelism full suite intermittently hit vitest "Failed to start forks worker / Timeout waiting for worker" errors (resource contention). With constrained workers (`vitest run --maxWorkers=3`) and on a re-run of `pnpm check`, all 194 files / 1047 tests passed with no failures; the errors were never assertion failures.
6. **Unrelated formatting revert.** A biome `useImportType` safe fix to `tests/p12-toolcatalog.test.ts` (unrelated to this task) was reverted to keep the change set scoped; lint remains green (0 errors).
