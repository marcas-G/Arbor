## P5-DG-01 resolution

Governance chose the decision/execution split: the **selection decision** stays
with the P2/P7 evaluator; the **canonical mutation** is an Application command
executed only through `CommandGateway`. P5 implements and integrates the
`SelectCurrentWork` handler (`packages/application/src/commands/select-current-work.ts`,
`apps/single-workspace/src/loop.ts`) and forwards the evaluator's exact
`workId`; no P1 `setCurrentWorkId` command was added. Recorded in P5 `01` §3.1,
P5 `05` §1, P2 `05` §4.
