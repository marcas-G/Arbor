## Acceptance Evidence

- `DomainError` is a closed tagged union; `DOMAIN_ERROR_TAGS` is the exact
  frozen rejection set, including frozen `IdempotencyConflict`,
  `AuthorityDenied`, `RevisionConflict` (§6A.1, §6A.5, §12.5).
- `FailureDisposition` has exactly the 8 frozen variants; exhaustive switch
  with `never` default.
- Normal alternatives / control results (`OutcomeUnknown`, `Blocked`,
  `Unknown`, `GovernanceBlocked`, `Interrupted`) are **not** error tags
  (§6A.1).
- No `ArborError` symbol and no base error class exported (namespace test).
- Type-level: `// @ts-expect-error` on an unlisted `_tag` is used, so an
  unlisted failure cannot be constructed.
- Non-canonical tag names for the §12.11 rejection rows are documented as
  planning-chosen (contract allows this; exact per-command contracts are P1).
