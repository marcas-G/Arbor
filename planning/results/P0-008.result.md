## Acceptance Evidence

- Lifecycle is exactly `Open | Completed | Cancelled`; exhaustive switch
  with `never` default; no `Current` / `Pending` exported symbol.
- `Completed` / `Cancelled` reversal rejected with
  `TerminalLifecycleMutation`.
- `CompleteWork` enforces all seven §3.6 clauses; stale/mismatched evidence
  returns `VerificationAcceptanceMismatch`; non-PASS verification rejected.
- `RefineWork`/`SteerWork` increment `WorkRevision`; weakening protected
  requirements rejected (`AuthorityDenied`).
- `CancelWork` requires governance authority and sets `Cancelled`.
- `Work.workspaceId` immutable (readonly); current-work predicate is pure.
- No infrastructure import in the domain package.

## Deviations

1. `weakensProtectedRequirements` is an explicit input fact (semantic
   weakening cannot be decided by a pure transition).
2. `workspaceAcceptsWork` is an explicit input fact (Workspace validity is
   L2/L3).
