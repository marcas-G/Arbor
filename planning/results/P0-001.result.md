## Environment method (important)

The host is Ubuntu 18.04 / **glibc 2.27**, which cannot run Node 24 natively
(official binary and conda-forge both require glibc ≥ 2.28; no `node:24`
image is reachable). The frozen baseline is satisfied inside a pinned image:

```text
arbor-node24:24.21.0
  = node:22-bookworm (glibc 2.36) + official Node 24.21.0 tarball + pnpm 12.4.2
```

All toolchain commands run through the project-level `env.sh` wrapper
(`arbor <cmd>`), which mounts the repo and the pnpm store on `/data` and maps
the host uid/gid. `~/.bashrc` is **not** modified.

Verified in-container:

```text

pnpm 12.4.2
npm  11.19.0
git  2.17.1 (host; repository initialized by P0-001)
```

## Deviations

1. **Node 24 provided via container, not host-native** — forced by host glibc
   2.27. The exact pinned version (24.21.0) and pnpm (12.4.2) are honored
   inside `arbor-node24:24.21.0`.
2. **`typecheck` command body** is `tsc -p tsconfig.test.json` (src + tests,
   `noEmit`) rather than `tsc -b --noEmit`, so test files are typechecked;
   `build` remains `tsc -b` with project references.
3. **`biome.json`** sets only `linter.enabled` (Biome 2.5.14 deprecated
   `rules.recommended`).
