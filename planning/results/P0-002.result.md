## Acceptance Evidence

- All §2.1 IDs exist with brands + codecs; `ID_SCHEMAS` keys equal
  `ID_PREFIXES` keys equal the 20-name §2.1 set.
- Type-level non-interchangeability: `@ts-expect-error` directives on
  `WorkspaceId → WorkId` and `ProjectId → WorkspaceId` assignments are
  **used** (typecheck would fail with an unused directive if the types were
  interchangeable).
- Round-trip `encode(ProjectId)(parse(ProjectId)(x)) === x`.
- Wrong prefix (`ws_` body into `ProjectId`) and malformed UUID body are
  rejected by the codec.
- `AgentId` / `RootWorkspaceId` / `PrimarySessionId` absent from both
  `ID_PREFIXES` and `ID_SCHEMAS`.
- `PermissionGrantId ↔ pgr_` asserted (DG-04).
- Generation is pure over `(timeMs, random: Uint8Array)`; earlier timestamp
  sorts before later; no ambient clock/RNG.

## Deviations

1. **Verification convention fixed.** `pnpm test -- <suite>` does not filter
   in Vitest 5 (the `--` terminates option parsing and the positional is
   ignored); `pnpm test <suite>` filters correctly. All task contracts and
   `tasks/README.md` were updated from `pnpm test -- <suite>` to
   `pnpm test <suite>`. Projection-layer fix, not a design change.
2. UUIDv7 generation is included per the P0-002 Outputs, implemented as a
   pure function of explicit `(timeMs, random)` inputs.
