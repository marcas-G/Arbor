**Date:** 2026-10-01

**Status:** COMPLETE / FORMALLY CLOSED

## Outcome

Arbor no longer uses HumanMessage as a retry scheduler. An immutable submitted
message owns user content; ConversationResponseJob owns response lifecycle;
ConversationAttempt owns execution evidence. Provider transport retry, model
output repair and conversation retry are independently bounded.
