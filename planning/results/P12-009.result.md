## Deviations / notes

1. **`ProjectEnvironmentPort` projection (production wiring).** The frozen `ProjectEnvironmentPort` (consumed by ownership writes, `OwnershipWriteServiceLive`, tool admission and `resolveRegions`) and the P11 `EnvironmentResolverPort` are distinct ports. Switching production to the real resolver therefore required an adapter-local projection `ProjectEnvironmentPortFromResolverLive` (in `adapters/environment-resolver-local`) that delegates `resolve` to the resolver `observe` and maps `EnvironmentResolverError → EnvironmentError`. This is a wiring projection, not a semantic change; the fake `ProjectEnvironmentPortLive` is retained for tests only and is no longer referenced by `composition.ts`.
2. **P5 fixture path migration.** `apps/single-workspace/test/p5-slice-acceptance.test.ts` inserted an ownership claim with the relative canonical path `"."`. The real resolver emits the frozen **absolute, normalized** path (P1 `04` §3.3), so the claim no longer contained the resolved intent region and the write tool was denied. The fixture is migrated to `resolve(".")` (the same cwd the resolver uses). This is a recorded fixture migration forced by the production-wiring deliverable; no production semantics changed.
3. **No golden byte re-baseline was required.** No test hardcodes a fingerprint digest or blob byte string; every digest assertion is relative (`toBe(anchoredFp.digest)`), and the `p11-snapshot-v1` literals are format markers unaffected by region encoding. The stringifier swap changes computed digests but all equality/round-trip assertions still hold (P12-005 §5.2 owns the blob format).
4. **Stringifier final branch.** Per `09` §4 the last branch maps any non-`FileTree`/`GitWorktree`/`DatabaseNamespace` value to the `ExternalResource` key (`address`). This is exactly why pre-migration raw-string fixtures collapsed; every producer/fixture is now object-encoded, so the branch is only a defensive fallback.
5. **`pnpm check` lint baseline.** Lint reports 292 pre-existing warnings (0 errors) across the repo; this task adds none.
