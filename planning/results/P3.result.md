## B-9 Remediation (appended 2026-09-23)

**Blocker (audit):** `decideRepair`/`repairFragment` and
`checkFreshness`/`requirementForDirective` were test-only; the production
driver returned `Failed` on the first `ModelOutputContractViolation` and never
gated `DecisionStale`.

**Frozen contract implemented (no new semantics):** P3 `06` §3 bounded repair,
P3 `06` §4 freshness/`DecisionStale`, DID §8.19; `GovernanceBlocked` preserved
(P3 `06` §6).

- **Bounded repair.** `driver.ts` `runDecisionTurn` runs
  `prepareTurn → ProviderRuntime.runTurn → decodeTurn`. On
  `decodeTurn().ok === false` it calls `decideRepair(REPAIR_POLICY, attempt,
  AGENT_DIRECTIVE_CONTRACT, reason)` (`REPAIR_POLICY = { maxRepairs: 2 }`,
  empirical N per P3 `06` §3). A `Repair` decision re-invokes `prepareTurn` with
  the A4 `OutputContractRepair` fragment under a fresh `ProviderTurnId`
  (`..._r<n>`, so the `provider_turns` PK is preserved) and re-validates. An
  `Exhausted` decision returns the frozen settlement (`Failed(ExecutionFailure)`,
  or `Interrupted(ControlledInterruption{RuntimeSafetyStop})` for a
  safety/looping signal) — not a generic `Failed` collapse on first violation.
- **`DecisionStale`.** Before executing each decoded directive the driver
  computes `requirementForDirective(directive)` and, when not `None`, re-reads
  the current `ControlBasis` (`currentControlBasis`, which reads the live
  `EnvironmentRevisionStore` face) and calls `checkFreshness(manifest.controlBasis,
  current, requirement)`. On a stale result the action is **not** executed; the
  driver breaks the directive loop and `continue`s the turn loop, i.e.
  re-`prepareTurn` under the new basis (P3 `06` §4). The `ControlBasis` is now
  captured into the Manifest per `prepareTurn` rather than once per drive.
- **`GovernanceBlocked`.** `prepareTurn → GovernanceBlocked` still settles
  `Interrupted(ControlledInterruption{reason:"GovernanceBlocked"})` unchanged.

**Files changed:**
- `packages/agent-runtime/src/driver.ts` — bounded-repair decision loop +
  per-directive freshness gate + per-turn `ControlBasis` capture.
- `tests/p3-driver.test.ts` — 4 new end-to-end tests on the real driver /
  `ModelContextLive` / `ProviderRuntimeLive` path (2 → 6 tests).

**Acceptance evidence (real driver path):**
1. `repairs a ModelOutputContractViolation and continues the loop to completion`
   — violated turn (no text/directive) → bounded repair → valid
   `CompletionClaim`; `Completed`; 2 `provider_turns` (fails pre-B-9, which
   settled `Failed` after the first violation).
2. `settles Failed after bounded repair attempts are exhausted` — 3 consecutive
   violations exhaust `maxRepairs:2`; `Failed(ExecutionFailure)`; exactly 3
   `provider_turns` (fails pre-B-9, which produced 1).
3. `does not execute a DecisionStale action and re-prepares instead` — a
   scripted `EnvironmentRevisionStore` moves `environmentRevision` `0 → 1`
   between `prepareTurn` and admission of an `InvokeTool`; the registered
   `InvokeTool` handler is never invoked, the driver re-prepares, and turn 1
   settles `Completed`; 2 `provider_turns` (the handler is invoked pre-B-9).
4. `recovers after a repair and continues to a later turn` — repair → valid
   `Communicate` observation → next turn `CompletionClaim`; `Completed`; 3
   `provider_turns`.
