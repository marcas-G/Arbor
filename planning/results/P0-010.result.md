## Acceptance Evidence

- Both `SessionBinding` variants exist; exhaustive switch with `never`
  default.
- Append is pure and append-only: original session keeps 0 entries; sequence
  is monotonic local (`[0, 1]`).
- Compaction creates a new checkpoint and increments `ContextEpoch`; the
  original session is unchanged.
- Schema field-presence test: `Session` has no `responsibility`,
  `currentWork(Id)`, `permission`, `dependency`, `verdict`, or `ownership`
  field; no business `lifecycle`/`status`.
- Session identity is durable (`sessionId` preserved across operations).
- No infrastructure import in the domain package.
