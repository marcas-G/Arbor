   depth-field tracked revision — future governance, not invented
   client-side (`01` role freeze).

   governance-scoped deferral to the P14 chat surface).
3. **chat-first**: deferred to P14+ per GQ2; no `SendMessage` surface
   exists in the client.
4. **uuidv7**: implemented locally (`cmd_<uuid-v7>`, RFC 9562 layout);
   test regex corrected to canonical 8-4-4-4-12 (task-note from P13-005).
5. **e2e "browser" role**: played by node fetch + native WebSocket against
   the real same-origin server (protocol-identical); jsdom render coverage
   lives in the apps/web suites. No playwright dependency was added (pin
   set frozen by `05` §4).
