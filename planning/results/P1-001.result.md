## Files

- `adapters/persistence-sqlite/src/client.ts` — `layer(config)` over
  `@effect/sql-sqlite-node`; WAL via `disableWAL:false`; PRAGMAs
  `foreign_keys=ON`, `busy_timeout=5000`, `synchronous=FULL` applied on open.
- `adapters/persistence-sqlite/src/migrate.ts` — forward-only migration runner
  keyed on `PRAGMA user_version`; refuses a newer DB; per-migration transaction.
- `adapters/persistence-sqlite/src/runtime.ts` — `Clock`/`IdGenerator` live +
  deterministic `ClockTest`/`IdGeneratorTest` layers.
- `adapters/persistence-sqlite/src/errors.ts` — adapter-internal
  `SqliteAdapterError`.
- `adapters/persistence-sqlite/test/{migrate,runtime}.test.ts`.
- dependency: `@effect/sql-sqlite-node@4.0.0-rc.115` (baseline pin).

## Acceptance Evidence

- Adapter opens a DB with WAL + the four settings (`foreign_keys` verified = 1).
- Migration runner applies a trivial migration, sets `user_version = 1`, is
  idempotent on re-run, and refuses a DB newer than the latest known migration.
- `Clock`/`IdGenerator` deterministic test layers.
- `pnpm check`: 25 files, 134 tests; `pnpm architecture` green.

## Deviations

1. Migration files are split into statements on `;` before execution (no
   embedded semicolons in DDL); documented in `migrate.ts`.
2. No DDL/tables here (P1-003); no transaction semantics (P1-004); no
   repositories (P1-005–007).
