# TOOL-AUTH-DG-01 — Execution Tool Capability Source

**Status:** OPEN

The frozen InvocationAuthority requires a capability set, but no current
canonical rule grants baseline capabilities to a non-human Work Execution when
no PermissionGrant exists. Hardcoded broad capabilities are unsafe; requiring
explicit grants without a bootstrap/lifecycle rule makes existing Agent tools
unusable. Awaiting manual governance in
`planning/proposals/agent-core-gap-closure-decision-draft.md`.
